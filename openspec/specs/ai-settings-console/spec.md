# ai-settings-console

## Purpose

定义 AI 设置页作为 agent 域控制台的职责：承载 OpenAI 兼容端点配置、AI 工具开关（置灰语义）、长期记忆管理面（与 agent 记忆工具同源）、agent 全局配置（性格模式/安全约束）。

## Requirements

### Requirement: AI 设置页承载长期记忆管理面

AI 设置页 SHALL 提供长期记忆管理入口，包含四动作：查看（索引条目列表 + 正文只读弹窗）、编辑（正文整文件覆写，索引标题与钩子不变）、删除（删单条记忆文件与索引行）、清空（删除全部记忆）。管理面读写的记忆存储 SHALL 与 agent 侧记忆工具同源——任一侧的写入对另一侧立即可见，两消费面不漂移。

#### Scenario: 查看记忆条目

- **GIVEN** agent 侧已写入 2 条长期记忆（各有索引行与主题文件）
- **WHEN** 用户在 AI 设置页打开记忆管理入口
- **THEN** 展示 2 条索引条目（标题 + 一句话钩子），点击条目可查看正文全文

#### Scenario: 编辑记忆正文

- **GIVEN** 记忆条目存在
- **WHEN** 用户查看条目后选择"编辑"，修改正文并保存
- **THEN** 该条目正文被覆写，索引行（标题与钩子）保持不变，agent 侧后续读取到新正文

#### Scenario: 删除单条记忆

- **WHEN** 用户在某条目查看弹窗中选择"删除"并确认
- **THEN** 该记忆文件与索引行被删除，其余条目不受影响

#### Scenario: 清空全部记忆需二次确认

- **WHEN** 用户在记忆管理面选择"清空全部记忆"
- **THEN** 弹出二次确认（提示将删除的条目数与不可恢复性），确认后全部记忆文件与索引被删除；取消则不做任何改动

#### Scenario: 空记忆状态

- **GIVEN** 记忆存储为空（无索引登记行）
- **WHEN** 用户打开记忆管理入口
- **THEN** 展示空态说明（尚无长期记忆、agent 会在使用中自动写入），不提供清空动作
