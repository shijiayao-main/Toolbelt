# log-workbench

## Purpose

定义日志分析工作台页的用户可见行为契约：一次分析 = 可回看 run 对象、三栏证据流交互、报告的因果链与假设三态呈现、工具页深链入口。工作台是「确定性基座 + agent 研判」叙事在日志域的产品化落点。

## Requirements

### Requirement: 工作台入口与结构化输入

日志工作台页 SHALL 提供结构化输入表单（非自由文本 prompt）：日志文件（可多选，支持 .alog/.xlog/.txt 拖入与选择）、问题时间点（yyyy-MM-dd_HH:mm:ss.SSS）、时间范围（分钟）、症状描述（文本，用于知识库匹配）、Tag 正则（可选——留空时 agent 经知识库反查自定）。

#### Scenario: 确定性管线可直接跑

- **GIVEN** 用户填入日志文件、时间点与范围，未配置任何 AI 能力
- **WHEN** 用户点击「开始分析」
- **THEN** 确定性管线（解密→时间过滤→环境扫描→Tag 过滤）照常执行并产出阶段产物，证据流按阶段锚点回显——管线可用性不依赖 LLM 端点

#### Scenario: AI 未开启时研判区明示降级

- **GIVEN** AI 工具开关关闭或端点未配置
- **WHEN** 工作台页渲染
- **THEN** 研判 agent 区域明示「配置模型服务后可获得根因研判」，确定性管线区不受影响；页面经 aiEnabled 面置灰可见（非隐藏）

### Requirement: run 对象持久化与回看

一次分析 SHALL 持久化为可回看的 run 对象：输入参数、管线各阶段产物路径、时间线（工具调用与阶段事件）、最终报告、状态（运行中/完成/中止/失败）。用户 SHALL 能从左栏 run 列表切换历史 run 回看完整证据与报告，能重命名与删除 run。

#### Scenario: 重启后 run 列表可恢复

- **GIVEN** 用户完成过至少一次分析并关闭应用
- **WHEN** 重新打开工作台页
- **THEN** run 列表按更新时间倒序展示历史 run；点开任一 run 可回看其输入、证据流与报告

#### Scenario: 运行中中止保全

- **GIVEN** 研判 agent 正在运行
- **WHEN** 用户点击「中止」
- **THEN** 运行停止但已产生的阶段产物、时间线条目与部分报告保留在该 run 下；run 状态标记为「中止」，可回看

#### Scenario: 删除 run 级联清理

- **WHEN** 用户删除一个 run
- **THEN** 该 run 的元数据与时间线条目一并删除；磁盘上的日志产物文件（解密 .txt、过滤产物）不随之删除（产物归日志目录）

### Requirement: 证据流交互（中栏）

证据流 SHALL 提供日志行级交互：级别着色（ERROR/WARN/INFO/DEBUG）、行内展开（±N 行上下文）、字段一键过滤（点击日志行字段即过滤该值）、阶段锚点跳转（管线各阶段与 agent 研判阶段的分界锚，点击跳转到对应区段）。

#### Scenario: 行级上下文展开

- **GIVEN** 证据流已展示过滤产物日志行
- **WHEN** 用户点击某日志行
- **THEN** 该行原位展开前后 N 行上下文（N 可调），再点收起；不离开当前滚动位置

#### Scenario: 报告引用跳转日志行

- **GIVEN** 报告面板中某条依据引用了日志行（时间戳）
- **WHEN** 用户点击该引用
- **THEN** 中栏证据流滚动到对应日志行并高亮

### Requirement: 报告面板（右栏）

报告面板 SHALL 呈现：因果链三段卡（根因→直接故障点→影响面）、假设三态徽章（已证实 ✓ / 已排除 ✗ / 存疑 ?——失败假设不抹除）、每条结论的日志依据引用（可展开原文并可跳转中栏）。报告 SHALL 落盘为 Markdown 文件存于应用数据目录（run 专属目录），禁止写入源码仓库或日志目录外的任意位置。

#### Scenario: 失败假设保留

- **GIVEN** 研判过程中某候选根因被验证推翻
- **WHEN** 报告生成
- **THEN** 该假设以「已排除」态呈现在报告中（含被推翻的依据），不静默删除

#### Scenario: 报告文件可独立打开

- **WHEN** 用户在 run 详情中点击「打开报告文件」
- **THEN** 以系统默认方式打开该 run 目录下的报告 Markdown 文件

### Requirement: 工具页深链入口

带产物跳工作台：XLog 解密等工具页的产物 SHALL 提供「深度分析」情境动作，点击后打开日志工作台并预填日志文件与解密产物路径；工作台 SHALL 接受该预填并直接可跑管线，无需用户重选文件。

#### Scenario: 解密产物一键深链

- **GIVEN** 用户在 XLog 解密页完成一次解密
- **WHEN** 用户点击产物卡片上的「深度分析」按钮
- **THEN** 应用切换到日志工作台页，输入表单已预填该解密产物路径，用户补时间点即可开始分析
