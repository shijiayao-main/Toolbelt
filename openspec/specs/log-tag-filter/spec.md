# log-tag-filter Specification

## Purpose

Log Tag 过滤工具：按用户指定的 Tag 正则从 .txt 日志文件中抽取匹配行并输出到新文件，支持多文件批量处理、逐文件任务状态跟踪与输入持久化，对齐应用内其他文件工具的任务卡体验。

## Requirements

### Requirement: Tag 正则与名称输入
系统 SHALL 提供 Tag 正则与 Tag 名称两个输入框。正则用于匹配日志行中的 Tag，名称用于输出文件命名。两者 MUST 在输入变化时持久化（经统一配置仓库），应用重启后自动恢复。

#### Scenario: 输入持久化
- **WHEN** 用户修改 Tag 正则或 Tag 名称
- **THEN** 系统将新值持久化；重新进入页面或重启应用后输入框恢复上次值

#### Scenario: 首次进入默认值
- **WHEN** 用户从未设置过正则与名称
- **THEN** 两个输入框为空

### Requirement: 多文件批量过滤
系统 SHALL 支持同时拖入或点击多选多个 `.txt` 文件，为每个文件创建独立的过滤任务并开始执行；扩展名不是 `.txt` 的文件 MUST 被忽略。

#### Scenario: 拖入多个文件
- **WHEN** 用户将多个 `.txt` 文件拖入拖放区
- **THEN** 系统为每个文件创建过滤任务并开始执行

#### Scenario: 点击多选
- **WHEN** 用户点击拖放区并在系统文件选择器中多选若干 `.txt` 文件
- **THEN** 系统为每个选中文件创建过滤任务并开始执行

#### Scenario: 忽略非 txt 文件
- **WHEN** 用户拖入的文件中混有非 `.txt` 扩展名的文件
- **THEN** 系统仅处理 `.txt` 文件，其余被忽略且不创建任务

#### Scenario: 缺少必填输入
- **WHEN** Tag 正则为空或 Tag 名称为空时用户提交文件
- **THEN** 系统不创建过滤任务，并给出明确的错误提示（"Tag 正则不能为空" / "Tag 名称不能为空"）

### Requirement: 过滤任务执行与状态展示

系统 SHALL 以任务卡列表形式展示所有过滤任务：每个任务卡显示文件名与状态（处理中 / 成功 / 失败），处理中显示进度指示，成功显示输出文件路径，失败显示错误原因。任务列表支持清空。

**文件编码（本变更新增）**：输入读取与输出写出 SHALL 显式按 UTF-8 编解码（输入源为 xlog/alog 解密产物，UTF-8 文本；不依赖平台默认编码，防止 JDK 17 打包态 Windows zh-CN 默认 GBK 下中文行读写乱码）。输出文件名 SHALL 经清洗：剔除文件系统非法字符（`< > : " | ? *` 与路径分隔符）与 Windows 保留名，防止用户输入的 Tag 名称导致创建失败或写出目标目录之外。

#### Scenario: 任务处理中

- **WHEN** 某文件正在执行过滤
- **THEN** 对应任务卡显示文件名与"处理中"状态（含进度指示）

#### Scenario: 过滤成功

- **WHEN** 某文件的过滤操作成功完成
- **THEN** 对应任务卡状态更新为成功，展示输出文件的完整路径

#### Scenario: 过滤失败

- **WHEN** 某文件的过滤操作失败（如正则非法、文件读取失败）
- **THEN** 对应任务卡状态更新为失败，展示错误原因

#### Scenario: 清空任务列表

- **WHEN** 任务列表非空且用户点击清空按钮
- **THEN** 系统移除全部任务卡，列表恢复为空

#### Scenario: 中文内容跨平台读写一致（本变更新增）

- **WHEN** 输入文件含中文行，在任意平台执行过滤
- **THEN** 输出文件内容与输入匹配行逐行一致（UTF-8 编解码），不因平台默认编码产生乱码

#### Scenario: 输出文件名清洗非法字符（本变更新增）

- **WHEN** 用户输入的 Tag 名称含文件系统非法字符（如 `a:b`）或 Windows 保留名（如 `CON`）
- **THEN** 非法字符被替换为安全字符后用于输出文件命名，过滤正常执行；输出文件不越出目标目录

### Requirement: 打开输出文件夹
过滤成功的任务卡 SHALL 提供"打开文件夹"按钮，点击后用系统文件管理器打开输出文件所在目录。

#### Scenario: 打开成功任务的输出目录
- **WHEN** 用户在成功状态的任务卡上点击"打开文件夹"
- **THEN** 系统调用系统文件管理器打开该任务输出文件所在目录

### Requirement: 任务列表头部
任务列表非空时，系统 SHALL 在列表上方显示任务数量标题与清空按钮。

#### Scenario: 查看任务数量
- **WHEN** 存在至少一个过滤任务
- **THEN** 列表头部显示"过滤任务 (N)"标题（N 为任务总数）与清空按钮
