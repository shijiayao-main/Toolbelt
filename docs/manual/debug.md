# Shell 调试

一句话：开发者的 Shell 会话实验场——「单次执行 / 保持会话」两种模式直接敲命令看输出。

## 什么时候用

- 验证一条 Shell 命令的输出与退出码，不想开终端
- 调试 Shell 工具页的自定义命令——先在这里试跑通再保存成按钮
- 需要一个**交互式**会话（发一条看一条，会话状态保持），比如 `adb shell` 进目标设备里连续操作

## 怎么用

1. 前提：到「设置」页（dock 系统区「设置」图标，快捷键 Ctrl+,）开启「开发者选项 → 显示调试入口」后，dock 系统区会出现「Shell 调试」图标（Ctrl+K 搜「Shell 调试」也能直达）
2. 页面顶部「单次执行 / 保持会话」段控选会话模式（单次执行 = 逐条独立运行；保持会话 = 先启动一条长命令如 adb shell，再逐条发命令进同一会话）
3. 「保持会话」模式下「启动命令」填入口命令（如 `adb shell`），点「启动」；会话开着时按钮变红色「关闭」
4. 在「输入命令...」框里输入命令，按 Enter 或点「发送」——输出区实时分 `[STDOUT]` / `[STDERR]` 两路显示
5. 输出台右上角有「清空」（只清当前模式的输出）和「复制」（复制全部输出文本）

## 注意

- 这是**开发者页面**：没有命令白名单与确认，敲什么跑什么——请清楚自己在做什么再用
- 页面顶部没有「返回」按钮——经 dock 或命令面板（Ctrl+K）切走即离开；会话不会被带走，切回来接着用，「保持会话」模式下记得用「关闭」正式收尾
- 单次执行跑长命令时「发送」会变「停止」——点「停止」中止当前执行并恢复输入
- 跑通了的长命令建议固化到「Shell 工具」页的自定义命令里，日常一键执行

## 常见问题

- **dock 里没有这个图标？** 它默认隐藏——去「设置」开「显示调试入口」
- **命令发了没输出？** 看会话是否还活着（启动命令可能已退出）；部分命令是持续输出型，等它跑完或直接「关闭」
- **切换模式被拦下？** 「保持会话」模式里有活跃会话时切不走，会提示「请先关闭当前 InteractiveShell 会话」——先点「关闭」收掉会话再切
