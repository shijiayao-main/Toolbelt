# Toolbelt 用户手册

> 面向使用这个工具的人。每个功能页在这里都有一篇「怎么用」。

## 怎么找功能（界面心智）

左侧 dock 侧栏分三段：

- **六个空间图标**（自上而下）：「工作台」「智能体中心」「Shell 工具」「飞书桥接」「工具」「设备观测」——快捷键 Ctrl+1 到 Ctrl+6 直达。「工具」页收 13 个子签（XLog 解密 / Tag 过滤 / 文件分割 / 时间戳 / 解压 / 日志对比 / 正则测试 / JSON 工具 / Base64 提取 / 哈希校验 / 颜色转换 / JWT 解析 / ULID 工具），进去后用页内子签切换
- **「命令」图标**：点它或按 **Ctrl+K** 打开命令面板，输入名字搜索直达任意页面或命令（`>` 只看命令、`@` 只看页面）；常用快捷命令如「截取时间区间日志」（按起止时刻切一段日志出来）、「对比两份日志」、「查看日志文件」也都在这里搜
- **剪贴板识别（推荐首页）**：空手打开命令面板（不输入任何字）时，面板会读一次剪贴板并识别内容类型，命中就在推荐首页列出对应工具的推荐行，点击直达「工具」页对应子签并**预填**内容到输入框（不会自动执行，落进去待你确认）。能识别的六类：
  - epoch 时间戳（10 位秒级 / 13 位毫秒级纯数字）→ 「时间戳」签
  - `.xlog` / `.alog` 文件路径 → 「XLog 解密」签
  - JSON 对象（`{` 开头 `}` 结尾可整体解析）→ 「JSON 工具」签
  - 长 base64 文本（解码出来是可读文字）→ 「Base64 提取」签
  - 图片 base64（解码出来是 PNG/JPEG/GIF/WebP）→ 「Base64 提取」签（图片内联预览）
  - GZip 数据（魔数开头可解压）→ 「解压」签（只跳页不预填——解压页输入面是文件拖入）
  
  识别是保守的：普通文本、代码片段、短单词不会出任何推荐；面板开着期间不跟随剪贴板变化重测，重新按 Ctrl+K 才会重测
- **系统区**（侧栏下方）：「AI 设置」「MCP 服务」「设置」，以及开启开发者选项后出现的「Shell 调试」

找不到入口时按 Ctrl+K 搜一下，什么都能搜到。

## 快速上手（第一次使用推荐路径）

1. **设置页**（dock 系统区）：配好 Shell 类型即可（adb 随应用自带，无需安装或配置）
2. **Shell 工具**（Ctrl+3）：最常用的快捷指令一键执行
3. **日志分析三件套**（Ctrl+5「工具」页内子签）：XLog 解密 → Tag 过滤 → 文件分割
4. **飞书桥接**（Ctrl+4）：把 AI 助手接到飞书里用
5. **设备观测**（Ctrl+6）：连上目标设备后复现问题、一键抓现场 logcat（adb 已内置）
