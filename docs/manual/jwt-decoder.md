# JWT 解析

一句话：把抓包 / 云控下发串里的三段式 JWT 粘进来——header/payload 明文展开，exp/iat/nbf 时间声明换算成人话并判读过期与否。

入口：「工具」页（dock 第 5 图标，快捷键 **Ctrl+5**）子签「**JWT 解析**」。

## 怎么用

1. 「JWT 文本」框粘贴三段式令牌（`header.payload.signature`）
2. 看 **Header（明文）** 与 **Payload（明文）** 两块格式化 JSON，各带复制钮可整段带走
3. 时间声明行把 `exp` / `iat` / `nbf` 的毫秒值换算成人类时间并给出判定——**已过期 / 尚未生效红色、有效绿色**，扫一眼可见；三个声明都没有时明示「payload 无时间声明」
4. 签名段旁有复制钮（拿去给后端验签用）

## 注意

- 🔴 **本工具只解不验签**——明文展开不等于令牌可信，不能据此信任令牌内容（界面明示这一点）
- 非 base64url 三段式结构给出人话错误，不静默
- 全部状态会话内有效，不持久化；本签是「工具」聚合页原生子签，命令面板没有对应的深入模式
