# 解压

一句话：把压缩包解到原文件旁边——普通包直接拖入，分卷组和 7z 也认。

## 什么时候用

- 拿到一大包日志（`.zip` / `.tar` / `.tar.gz` / `.tgz` / `.gz`），想解开继续用「Tag 过滤」「文件分割」加工
- 文件被切成了分卷（`.zip.001…` / `.7z.001…` / `.z01…`），别处解不开

## 怎么用

1. 进入页面：点左侧 dock 的「工具」图标（快捷键 Ctrl+5），切到「解压」子签；或按 Ctrl+K 打开命令面板，输「解压」直达
2. 把压缩包（或整组分卷，支持多选）拖进中央投放区「拖入压缩包或分卷（支持多选）」，松手即开始
3. 在「解压任务」列表看进度（还没任务时显示「还没有解压任务」），完成后去原文件旁边的 `文件名_extracted` 文件夹取结果

### 分卷怎么拖

- 三类分卷都支持：**zip 字节切分**（`.zip.001`、`.002`…）、**7z 切分**（`.7z.001`…）、**PKZip 规范分卷**（`.z01`、`.z02`…）
- 一次拖入**整组**：多选全部分卷一起拖；PKZip 分卷的末卷（同基名的 `.zip` 文件）必须在内——中央目录在末卷里，缺了会提示「缺少分卷末卷……补齐后重新拖入」
- 任务卡上会标组徽章（如「zip 切分组 · 3 卷」），按组整体跑

### 命令面板的快捷入口

Ctrl+K 里的「解压压缩包」命令适合普通单包；拖了分卷或 7z 时它会引导你「点「打开页面」进解压页处理」——分卷逻辑只在页面里。

### 任务卡上的操作

- 行尾「⋯」按钮（右键任务卡同款菜单）：进行中的可「取消任务」，失败的可「重试」或「打开文件夹」
- 成功的任务卡菜单还有**「送 XLog 解密」**：解出来的 `文件名_extracted` 目录里若装的是加密日志（`.xlog` / `.alog`），点它直接接力解密，不用手动搬文件：
  - 目录里**只有 1 个** `.xlog` / `.alog`：文件路径自动填进「解密 XLog 设备日志」的表单，补上私钥（没配过的话）就能直接解密
  - 目录里有**多个**：自动跳到「工具」页的「XLog 解密」子签，目录里的 `.xlog` / `.alog` 全部批量建卡开始解密（逐个卡独立跑，产物重名时会先弹「产物已存在」确认框）
  - 目录里**一个都没有**：提示「拖入的 N 个目录内没有可处理的文件（空目录或类型不符）——纯文本 .txt 日志可整目录拖入「Tag 过滤」页」，说明这个包解出来的不是加密日志；里面的普通 .txt 日志可以直接整目录拖进「Tag 过滤」页处理

## 注意

- **安全上限**：一次解压最多 10 万个条目、总量 2GB、单条目压缩比不超过 200 倍——超了会中止并提示「疑似解压炸弹，已中止」。这是防护不是故障：把可疑来源的压缩包挡在写满磁盘之前
- 压缩包里带绝对路径 / `..` 穿越 / 链接的条目会被跳过（只解压落在本文件夹内的部分），防止压缩包把文件写到别处
- 解压结果在原文件**同级**的 `文件名_extracted` 目录，不会动原压缩包

## 常见问题

- **提示「已识别为 rar 风格字母卷，该格式不支持解压」？** 只支持上面列的三类分卷；`xxx-partaa` 这类 rar 风格字母卷请先用压缩软件重切
- **拖入没反应？** 看后缀是否在支持列表（`zip / tar / tar.gz / tgz / gz`、三类分卷、`7z`）；分卷要整组一起拖
- **分卷缺一卷会怎样？** 页面会按组检查卷号连续性，缺哪卷提示哪卷，补齐后重新拖入即可
