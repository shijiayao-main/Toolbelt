# XLog 解析

一句话：把设备上加密的 `.xlog` / `.alog` 日志文件解密成可直接阅读的文本。

## 什么时候用

- 拿到设备导出的加密日志（`.xlog` 或 `.alog` 后缀），肉眼打不开
- 需要批量解密一批日志文件，接着用「Tag 过滤」「文件分割」继续加工

## 怎么用

### 第一次使用

1. 进入页面：点左侧 dock 的「工具」图标（快捷键 Ctrl+5），切到「XLog 解密」子签；或按 Ctrl+K 打开命令面板，输「XLog 解密」直达
2. 在「私钥」栏（`输入 xlog 私钥（加密日志必填）`）填入你项目的私钥——**加密日志必填**，明文日志可留空。输入一次即持久保存，下次不用重填；还没填时页面顶部会有黄色提示「尚未配置 xlog 私钥——加密日志解析前必填；输入一次即持久保存」
3. 私钥栏右侧有「显示 / 隐藏」切换，明文核对完记得切回「隐藏」

### 解密文件

1. 把文件拖进页面中央的投放区（「拖入或点击选择 .xlog / .alog 文件（支持多选与目录）」），或点击选择；**整目录也可以直接拖**——会自动找出目录里的 .xlog / .alog 逐个建卡（解压产物 `_extracted` 目录拖进来即可），目录里没有可处理文件或文件过多（超 1000 个）会整批提示拒绝
2. 松手即开始解密，「支持同时拖入多个文件批量解析」
3. 「解析任务」列表里看进度（还没任务时会显示「还没有解析任务」的空态引导），完成后输出目录里出现同名 `.txt` 文件，直接打开阅读
4. **从解压页接力**：在「解压」子签解完一个包后，右键成功的任务卡（或点「⋯」）选「送 XLog 解密」——目录里有多个 `.xlog` / `.alog` 时会自动跳回本子签并把它们全部批量建卡，不用回文件管理器逐个拖

### 任务卡上的操作

- 完成的任务卡带「深度分析」和「打开文件夹」按钮：点「深度分析」把解密产物直接送进「工作台」开始 AI 深度分析；点「打开文件夹」跳到产物所在目录
- 任务卡行尾有「⋯」按钮（右键任务卡同款菜单）：进行中的任务可「取消任务」；失败的任务可「重试」或「打开文件夹」
- 成功的任务卡菜单还有**「查看」**：在应用内直接打开产物文件，弹出「查看日志」窗口，不用出应用（产物是目录时该入口自动隐藏）。窗口里能做的：
  - **滚动阅读**：日志行按级别着色；滚动到底自动往后续读，滚回顶部自动往前补上下文
  - **搜关键词**：在搜索框（提示「关键词，回车搜索/下一处」）输入关键词按回车——跳到第一处匹配，旁边回执显示「N 处匹配」或「无匹配」（匹配超过 1000 处显示「超 1000 处」）；同一个关键词再按回车就跳下一处，点「**上一处**」往回退
  - **跳行号**：在输入框（提示「行号，回车跳转」）填行号按回车，直达那一行
  - **跳级别**：「**上一处错误**」/「**下一处错误**」连点逐个错误行移动，「**上一处警告**」/「**下一处警告**」同理跳警告行——逐错误排障不用肉眼扫着色行
  - **跳时间戳**：在输入框（提示「时间戳 yyyy-MM-dd HH:mm:ss，回车跳转」）直接粘贴从日志里复制的时间戳，按回车或点「**跳转**」直达那个时刻（含）之后的第一行日志；毫秒可以省略，日期和时间之间用空格。格式不对会提示「时间格式无效，期望 yyyy-MM-dd HH:mm:ss.SSS（可空格分隔、省略毫秒）」；该时间之后没有日志会提示「该时间之后无日志行」
  - **选中复制**：日志行上的文字可以直接按住鼠标拖选，松手后按 Ctrl+C 复制——想带走某一行证据（贴进报告、发给别人）不用先导出文件；注意拖选只对当前屏幕内的行有效，先滚动或跳转到目标行附近再选
  - **送 AI 深度分析**：看完想直接发起分析时点窗口底部的「深度分析」，当前文件直接送进「工作台」开始 AI 深度分析，不用再手动把文件搬过去；窗口若是带时间点定位打开的（比如从工作台报告点依据跳过来的），那个时间点也会一并带过去、自动填进「问题时间点」框，不用再抄一遍
  - **送 Tag 过滤**：看到可疑 Tag 想把整个文件按 Tag 过一遍时，点窗口底部的「送往 Tag 过滤」——当前文件路径自动填进「按 Tag 过滤日志」的表单，补上 Tag 正则和输出标记就能执行，不用回工具页手动填路径
  - **送时间截取**：想按时间区间把整段日志切出来时，点窗口底部的「送时间截取」——当前文件路径自动填进「截取时间区间日志」的表单；窗口若是带时间点定位打开的（比如从工作台报告点依据跳过来的），那个时间点还会一并带过去、自动填进「起始时刻」框，不用再抄一遍；「结束时刻」留空待填——不填就点执行会提示「未填写结束时刻」，补上后执行，截出的文件落在原文件旁边
  - **送 XLog 解密**：把还没解密的加密件（`.xlog` / `.alog`）直接打开时，窗口会提示「需先解密产出 txt」，底部同时出现「送 XLog 解密」按钮——点它，文件路径自动填进「解密 XLog 设备日志」的表单，补上私钥（没配过的话）就能直接解密

- 成功的任务卡菜单还有**「送飞书」**：把产物文件直接发进飞书桥接的接收会话，不用手动搬运（前提是飞书桥接正在运行，没在跑时该菜单项置灰；产物是目录时不出现）

### 接力加工

解密出的文本可以继续，都在同一页的子签里切换：

- 用「Tag 过滤」按业务 tag 提取关注模块的日志块
- 用「文件分割」把超大文件切成好传的小片

## 注意

- 私钥填错不会报「密钥错误」，只会解出乱码或直接失败——排查时优先核对私钥
- `.xlog` 与 `.alog` 两种加密格式都支持；解密结果与原文件同目录存放
- 拿到手的文件其实已是明文（只是挂了加密后缀）也没关系——会自动识别并直接复制成 `.txt`，不走解密
- 输出文件已存在时会弹「产物已存在」确认框：点「覆盖重跑」清掉旧产物重跑，点「取消」则旧产物原样保留
- 有任务处理中时投放区会拒收新文件，等当前批次跑完再拖

## 常见问题

- **拖入后没反应？** 看文件后缀是否为 `.xlog` / `.alog`；加密日志没配私钥会被拦下，提示去「工具」页 XLog 解密签配置
- **想要一次处理多种格式？** 分别用「XLog 解密」子签（`.xlog`/`.alog`）与「解压」子签（压缩包）即可——两者都在「工具」页内切换，解压的完整说明见 [解压](archive.md)
