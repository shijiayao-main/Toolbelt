# 日志对比

一句话：把「改动前后」的两份日志放在一起比差异——几万行肉眼找不出的行为变化，几秒列出来；或用「分布对照」直接看问题日志相对健康基线**多冒了什么 Tag、哪些级别变多**。

## 什么时候用

- 同一个问题两次复现，想找出两份日志的行为差异（哪一行多打/少打/变了）
- 两个版本各抓一份日志，对比改动是否生效、有没有引入新行为
- 两份日志**时钟不同**（不同设备/不同启动），只想比行为不想被时间戳差异淹没
- 手里有一份健康基线日志，想知道问题日志的 Tag/级别分布哪里「不新鲜」了（新增 Tag、E/F 变多）

## 怎么用

1. 进入页面：点左侧 dock 的「工具」图标（快捷键 Ctrl+5），切到「日志对比」子签；**不想进页面**也可以按 Ctrl+K 搜「对比两份日志」——填两个文件路径直接出 `.diff` 产物（全等不落产物、差异超限时结果里会说明）
2. 把两份文件分别拖进两个投放区——「基准（改动前）」和「被对比文件（改动后）」；**一次拖两份**会自动填满两个槽（第三份忽略并提示）
3. 选模式：「**行级对比**」（默认）或「**分布对照**」（见下节）
4. 行级模式下，两份日志时钟不同时打开「时间戳归一化对齐」开关（仅行首时间戳不同的行视为同一行——比行为不比时钟；该开关只在行级模式显示）
5. 点「开始对比」：
   - **行级**：差异以块（hunk）为单位列出，带 `@@` 行号头，删除行、新增行、上下文行分色标注
   - **分布对照**：块级统计对照面板（见下节）
6. **行级差异行可以直接点**：点击某一行，在应用内查看器打开它所在的那份文件（删除行和上下文行打开基准文件、新增行打开对比文件）并直接定位到这一行——前后几百行上下文一眼可见，不用自己开查看器手输行号；时间戳归一化打开时同样定位到原文件的真实行号
7. 行级模式点「导出」把结果存成 unified diff 文件（落对比文件旁边，文件名带 `.diff`）
8. 点「送飞书」直接把这份 diff 发到飞书会话（前提：飞书桥接正在运行——没运行时按钮置灰并提示先去启动；发送前会自动重新导出，保证送出的是最新对比结果）

## 分布对照（新鲜度视图）

排障常见动线：拿一份**健康基线日志**对比**问题日志**。切到「分布对照」模式再点「开始对比」，得到块级统计对照（≠ 行级内容差异——「哪几行不一样」归行级模式，两者互为补充）：

- **新增 Tag**：对比侧出现、基线侧没出现的 Tag（按频次降序）——问题日志里「新冒出来」的业务域一眼可见
- **共有 Tag 频次增减**：两边都有的 Tag，频次差值（对比 − 基线，正 = 变多、负 = 变少，按差值大小降序）
- **E/F 增量单列**：错误/致命块数差值单独一行——「环境变坏」的第一信号不与其他档混排
- **其余级别块数差值**与**未识别 Tag 头行**差值（两侧如实分列、不归因）
- 两份日志分布完全一致时显示「两份日志的 Tag/级别分布一致（基准 N 块 / 对比 M 块）」

## 注意

- 完全相同的两份日志会显示「无差异」；归一化开关打开时，只有时间戳不同的行不算差异
- 两份日志差异特别大（超过对齐上限 4096 处）时，会提示「差异超过对齐上限，中间区域已整体替换展示、未逐行对齐」——按提示开归一化或缩小对比范围，结果仍然完整只是中间不再逐行标注
- 行级与分布两种模式的结果**分立保存**——切模式不会丢掉已在台的结果
- 对比中不能更换文件（提示「对比进行中，请等待完成后再更换文件」），等完成再换
- 缺文件时点「开始对比」会提示缺哪一份（「基准文件尚未选择…」），点「清除该提示」可关掉横幅

## 常见问题

- **差异块里的行号怎么看？** `@@ -旧文件行 +新文件行 @@` 头标出两份文件各自的窗口位置，删除/新增行按 `−/+` 前缀分色
- **导出的文件在哪？** 对比文件旁边，文件名 = 对比文件名 + `.diff`，可直接贴进工单或发给同事
- **想在命令行批量对比？** log-tools CLI 也支持：`java -jar log-tools-all.jar --type diff -f <基准> --other <对比> [--normalizeTimestamps]`（见开发者知识库 docs/log-tools.md）
