# 会话

一句话：跟 AI 开一场调查会话——你只描述目标，AI 会主动向你索要它缺的信息，边问边干，产出留档可续聊。

## 什么时候用

- 想让 AI 做一次开放式调查（例：分析这份日志里相机启动失败的原因），但不知道该一次给齐哪些信息
- 手头资料不全，希望 AI 列清单问你要，而不是自己来回试
- 想把一次调查的完整对话与证据留档，之后随时回来追问

## 怎么用

### 1. 进入页面

点 dock 第二个空间图标「智能体中心」（快捷键 Ctrl+2），停在第一个子签「会话」。前提：先在 dock 系统区「AI 设置」配好模型服务，否则「开始」按钮会写明「AI 功能未开启——请先到「AI 设置」页开启」。

### 2. 开启新会话

1. 「能力挑选」区勾选本次要用的能力（可多选）：
   - 「日志分析」：根因研判——解密 → 过滤 → 取证 → 知识库反查，产出五部分结构化报告
   - 「语音纪要」：把转写原文整理为三段纪要（要点 / 待办 / 结论），原文不改写
   - 全不选 = 通用对话
2. 「目标」框一句话描述本次会话要干什么（例：描述本次会话的目标，例如「分析这份日志里相机启动失败的原因」）
3. 点「开始」进入会话

### 3. 回答 AI 的主动提问

AI 缺信息时会在输入框上方弹出「Agent 需要补充信息」卡片（带「AskCard · 主动提问」标签），可能含多个输入框 / 单选 / 多选：

- 填完点「提交」；暂时没有就点「暂无补充」
- 多字段时 Enter 在字段间逐个下移，最后一个字段回车才提交整卡（卡上有键面提示「Enter 逐字段下移，末字段提交整卡」）

### 4. 会话中继续互动

- 底部输入框「回答 / 追问（Enter 发送，Shift+Enter 换行）」继续对话；日志、转写文本等文件可拖进「拖入文件作为附件」登记给 AI 使用
- AI 运行中插话不会丢：先显示「已排队 N 条（本轮结束后自动发送）」，本轮结束自动发出；队列满了会提示「队列已满——本轮结束后再插话」
- 运行中可点输入框右侧的「停止」图标中止本轮
- AI 要读你登记之外的文件路径时，会弹「路径授权」确认卡（标着「围栏外」）：「允许」（或按 Enter）后本会话内该路径免确认；「拒绝」（或按 Esc）则跳过该访问继续执行
- 时间线里 AI 产出的证据文件以条目形式挂在对应工具卡上，点一下直接跳「日志工作台」深挖该文件

### 5. 管理历史会话

- 右侧栏「历史会话」列出全部会话，点行进入继续聊；悬停出「改名」和「删」——「删」会弹确认「将删除会话「某某」及其全部消息记录，不可恢复。」
- 主区「最近会话」卡（默认收起）取最近 5 条，是侧栏收起 / 窄窗时的兜底入口
- 会话运行中点「返回新建表单」会弹确认：「当前会话正在运行：返回将中止本轮运行，已排队的 N 条插话一并丢弃（不可恢复）。」
- 会话完成时若你正停在别的页面，会收到「会话「某某」已完成」提示

## 注意

- 会话不会过期：随时回来继续追问，AI 会接着此前的对话往下干（超长会话只携带最近一段历史）
- 会话运行中点历史会话切换会被拦下并提示「当前会话运行中，请先中止或等本轮结束后再切换」
- 删除会话不可恢复——确认卡是唯一的后悔机会

## 常见问题

- **「开始」点不了？** 按钮上写着原因：没配 AI（去「AI 设置」）或「目标」还没填
- **AI 一直不向我提问？** 信息够全时它直接开工；只有缺信息时才弹「Agent 需要补充信息」
- **运行中的插话会丢吗？** 不会——先排队（界面有「已排队 N 条」回执），本轮结束自动发送
- **想删掉某次会话？** 在「历史会话」里悬停该行点「删」，确认后即彻底删除

## 调查空间（第四子签）

一句话：调查空间 = 一次调查的聚合容器——相关文件、会话、研判产物自动聚在同一个名字下，事后一眼找全。

「智能体中心」第四个子签就是「调查空间」（Ctrl+2 后切到第四签）。

### 什么时候用

- 一次排障涉及多个文件、多轮会话、好几份研判报告——想把它们归到一起，别散在原地找不回
- 事后复盘：这次调查都看过哪些文件、开过哪些会话、出过哪些报告

### 怎么用

1. 点「新建空间」建一个新调查，点列表里的空间行即把它设为「当前空间」
2. 东西自动进来，不用手动拖：
   - 各工具产物卡上的「深度分析」带入文件时，自动记入当前空间
   - 在当前空间下发起会话或工作台研判，会话和报告也自动归属
3. 空间行尾可以展开成员明细、重命名；「归档」收起旧调查（归档区点行取消归档）
4. 「删除」只删这条聚合记录，不删除成员的文件/会话/产物本体（确认卡上有明示）

### 注意

- 列表按最近触达倒序，底部一行说明空间是什么；空态提示「Ctrl+K 召唤工具，或点右上 + 新建空间」
- 归档不是删除：归档的空间取消归档后原样回来
