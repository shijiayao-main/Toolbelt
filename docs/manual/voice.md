# 语音转写

一句话：把音频文件离线转成文字（不联网可用），还能边说边出字地实时录音；配上 AI 后一键把转写原文整理成纪要。

## 什么时候用

- 会议 / 访谈 / 口述的录音，想快速出一份文字稿
- 想边说边记：开着实时录音，说话内容逐段变成文字
- 转写完想再让 AI 提炼出要点、待办和结论

## 怎么用

### 1. 进入页面

点 dock 第二个空间图标「智能体中心」（快捷键 Ctrl+2），切到「语音转写」子签；或按 Ctrl+K 搜「语音转写」直达。

### 2. 首次使用：准备转写模型

1. 首次进入会出现「转写模型未就绪」引导卡：点「下载模型」下载 SenseVoice int8 模型（约 227MB，一次下载长期复用）
2. 下载卡显示进度、速度与剩余约需时间；可随时点「取消下载」（已下载分片保留，但下次会重新下载）
3. 下载失败 / 校验失败时：点「重试下载」或「重新下载」；网络不通就点「打开模型目录」，手动把 `model.int8.onnx` 与 `tokens.txt` 两个文件放进该目录，重启应用即就绪（跳过下载）
4. 用「实时录音」还需要一个很小的 VAD 切段模型（silero_vad.onnx，约 629KB）：会出现「VAD 模型未就绪」引导，点「下载 VAD 模型」即可

### 3. 转写音频文件

1. 把音频拖进「拖入或点击选择音频文件（wav / mp3 / m4a / flac / ogg，可多选）」投放区（拖进去会提示「松开以转写」），支持多选批量
2. wav 直接转写；mp3 / m4a / flac / ogg 需要系统安装 ffmpeg，缺了会明确提示（转存成 wav 可绕开）
3. 「转写任务」列表看进度；完成后转写文本自动保存为 `~/.toolbelt/voice/transcripts/音频名.md`
4. 完成的任务卡右键（或点卡上「⋯」钮）：「查看」在应用内直接读转写稿、「AI 整理」发起纪要整理、「打开文件夹」跳到产物目录

### 4. 实时录音（边说边出字）

1. 「实时录音」区点「开始录音」——麦克风经 VAD 自动切段、逐段转写，全程离线
2. 录音中显示时长与音量条，下方逐段滚动出字（带 #1、#2 段号）
3. 点「停止」结束（结尾一句不会丢）；停止后可点「整理纪要」把整段文字交给 AI，或「清空」重置再来一轮

### 5. AI 整理纪要（需先配好「AI 设置」）

1. 转写完成的任务卡上右键选「AI 整理」（或录音停止后点「整理纪要」）
2. 整理中弹「AI 整理中」进度卡（带秒表计时），可点「取消」
3. 完成后弹出「AI 整理纪要」审阅卡：默认显示结构化纪要，可点「查看原文」切换核对原文（「查看纪要」切回）
4. 点「采纳」把纪要写进页面下方「纪要（已采纳）」区；点「取消」不写回
5. 采纳后点「导出纪要文件」存出 Markdown 文件，界面显示「已导出：<完整路径>」

没配模型服务时，页面会提示「配置模型服务后可对转写原文做 AI 整理纪要（要点/待办/结论）。」——离线转写不受影响，照常可用。

## 注意

- 转写支持中文、英文、日语、韩语、粤语，全程离线、不上传
- 超过 60 分钟的音频只转写前 60 分钟，转写稿开头会明确标注截断说明
- 转写稿在 `~/.toolbelt/voice/transcripts/`，导出的纪要在 `~/.toolbelt/voice/notes/`
- 麦克风被其他程序占用时，录音区会显示错误提示，关掉占用程序再开始

## 常见问题

- **「开始录音」点不了？** 转写模型或 VAD 模型还没就绪——按钮旁会提示去「上方模型准备区」下载
- **拖入 mp3 / m4a 报错？** 非 wav 格式需要系统安装 ffmpeg；或先把音频转存成 wav 再拖入
- **任务卡上看不到「AI 整理」？** 该项只在配好模型服务后出现——先到 dock 系统区「AI 设置」配置
- **整理失败了？** 审阅卡会显示「整理失败」与原因；通常是模型服务配置问题，检查「AI 设置」后重试
