# Base64 提取

一句话：设备日志把截图/视频帧以 base64 整段嵌在日志行里——粘进来自动嗅探出长 base64 段，点一下就解码成图片内联预览或文本回显。

入口：「工具」页（dock 第 5 图标，快捷键 **Ctrl+5**）子签「**Base64 提取**」。

## 怎么用

1. 「日志文本」框粘贴含 base64 段的日志行——长度 ≥ **64 字符**的 base64 token 自动嗅探为候选（短 hash / session id 这类噪声不进列表）
2. 「提取候选」列表逐条显示序号、字符数和首尾片段（长 token 只给两端辨认用，不整段铺开）；点击选中
3. 「候选 #N 预览」显示解码结果：
   - **图片**（按文件头魔数识别 PNG / JPEG / GIF / WebP）：内联缩放预览（超大截图按高度上限缩放，不撑破页面）
   - **可读文本**：直接回显（超过 10000 字符截断明示）
   - **失败**：坏 base64 / 未知格式给出人话原因，不静默
4. 文本一变，旧候选与选中即失效——改了粘贴区记得重新点候选

## 注意

- 候选数上限 64 个，超过截断明示；单个 token 超过 8MB 拒绝解码并明示
- 解码全在后台线程（含图片解码），超长 token 不会卡界面
- 标准字母表优先、url-safe 字母表（`-`/`_`）兜底，两者都拒收才判非法
- 全部状态会话内有效，不持久化；命令面板 Smart Detection 检测到剪贴板里的 base64（含图片 base64）可一键跳本签并预填
- 本签是「工具」聚合页原生子签，命令面板没有对应的深入模式
