# 设置

一句话：外观、Shell 环境、日志存储与开发者选项都在这里配置。

## 什么时候用

- 第一次使用：配好 Shell 类型即可。adb 随应用自带，无需另装或配置路径
- 想换主题/配色，或从一张图片提取一套配色
- 排查问题需要开启本地日志存储，或打开隐藏的调试页

## 怎么用

进入方式：点左侧 dock 系统区（侧栏下方）的「设置」图标（快捷键 Ctrl+,），或按 Ctrl+K 打开命令面板输「设置」直达。

### 外观

- 「外观模式」：跟随系统或手动指定深浅色，更改即时生效
- 「配色方案」：预设主题 / 自定义种子色 / 从图片提取，更改即时生效——「从图片提取配色」选一张图，整套主题色随图生成

### Shell 环境

- 「Shell 类型」：选择执行 Shell 命令时使用的 Shell，需与你配置 PATH 的 Shell 一致
- 「内置 ADB」：没有需要填的路径——adb 随应用分发。点「检测可用性」可查看版本号，确认可用

### 日志与调试

- 「开启日志存储」：开启后会在日志目录（页面会显示具体路径）下生成日志
- 「开发者选项 → 显示调试入口」：开启后 dock 系统区（侧栏下方）会出现「Shell 调试」图标
- 「开发者选项 → 启动耗时」：显示本次启动各初始化器的毫秒耗时分布（按高优/低优分组带合计，失败的条目带「失败」标记）——排查「启动慢」时不用翻日志；启动失败短路时记录可能不完整

## 注意

- 「检测可用性」失败时看页面给出的具体原因（内置文件缺失 / 无法执行 / 无版本输出）
- 设置即时保存，不需要点保存按钮

## 常见问题

- **Shell 工具页设备列表空？** 先回这里点「检测可用性」；通过后仍无设备，多半是手机端未开 USB 调试或驱动/权限问题（设备状态栏会给出原因）
- **Shell 调试页找不到？** 它默认隐藏——开启「开发者选项 → 显示调试入口」后出现在 dock 系统区
