# 设备观测

一句话：连着设备的这块「驾驶舱」——投屏看屏操控、logcat 抓现场、性能采样画曲线、文件浏览器、应用管理、界面层级树，复现问题时的全套采集一键齐起。

入口：dock「设备观测」空间（第六个空间图标，快捷键 **Ctrl+6**）。

## 空间总览

- **设备栏**（页头行右侧）：设备检测/刷新/选择（多设备弹窗选择）、**「转无线」**一键钮（见下文）；没配 adb 路径时给「去设置配置 adb 路径」入口
- **四个子签**：「观测台 / 文件 / 应用 / 布局」——四个子签共用同一个目标设备（设备栏选定为准）；切子签不中断进行中的抓取/投屏/采样（引擎是全局单实例）
- logcat 实时抓取的完整用法（过滤语法、武装捕获、标记锚点）见 [logcat 实时抓取](logcat.md)

## 观测台（默认子签）

从上到下五块：

### 复现记录（一键三采）

顶部的「复现记录」行把 **logcat / 性能 / 投屏** 三个采集通道压成一钮：

- 点「**开始复现记录**」——三通道同起（已在跑的跳过并单列提示「logcat 已在抓取，跳过」这种）；聚合回执一条（不会逐个刷屏）
- 点「**停止复现记录**」——在跑的通道同停（空闲成员如实分列「本就空闲」）
- 行内三个徽标（logcat/性能/投屏）实时显示各通道「在跑/空闲」
- 复现问题时的标准动线：点开始 → 操作设备复现 → 点停止——日志、性能曲线、投屏画面/录像一次拿全

### logcat 实时抓取

抓现场日志（查询过滤、武装捕获、标记、产物四连送）——完整用法见 [logcat 实时抓取](logcat.md)。

### 投屏预览

投屏条目是**单行启动卡**：投屏的展示和操作全部在独立窗口里（窗是投屏唯一的使用场景），行卡只管「启动 + 出问题时给回执」——点「开始投屏」（点整行同效）直接拉起投屏独立窗口，连接成功后画面自动在独立窗展示（scrcpy 协议直连，首次连接约数秒：推送 server → 建隧道 → 握手）：

- **行尾主钮**：未在投屏/正常停止 = 「开始投屏」；投屏中 = 「聚焦窗口」（把独立窗带回前台，含从最小化恢复——任务栏恢复不可依赖，用这个钮）；连接中 = 禁点回显「连接中…」；失败 = 「重试」。**关窗即停止投屏**——想停直接关窗即可
- **回执细行**（行卡下恒显，有错才现）：无设备 / adb 未配置的前置提示（含「去设置」直达）；失败终态显式给红字原因（可「知道了」收起），主钮变「重试」；连接迟迟不出画面（等窗超时）也有显式回执与「重试」入口
- 独立窗内承载会话操作面：设备画面（**画面即遥控器**——鼠标点击/拖动触摸注入、滚轮滚动；连接中不可操作）、「常用按键」键排（HOME/返回/菜单等）、「输入文本」/「存入设备剪贴板」、**保存快照**（**按下时刻设备端实拍**——adb screencap 直取设备当下屏幕，恒原生分辨率、不受预览画质档影响；实拍失败自动回退预览画面帧。设备名+时间戳命名，落 `~/Documents/Toolbelt/snapshots/`，按后按钮置忙直至回执；回执行持久显示路径，可「打开所在文件夹」或「**送飞书**」——截图直发桥接接收会话，桥接未运行置灰并提示原因）、**录像**（边看边录，画面原样封装成 mp4 **零重编码**；静止画面不产帧，动一下设备画面即开始；停止后回执显示完整路径，落 **`~/Documents/Toolbelt/recordings/`**，可「打开所在文件夹」；产物时间轴从 0 起（首帧归零），时长如实、进度条可任意拖动；分辨率变化等异常收尾在回执里如实注记，失败不留不可播的残件）、**画质档位**（顶栏「画质」钮弹层，投屏未在跑时可改，**下次开始投屏时生效**，投屏中置灰并注记）：
  - 码率：2M / **8M·默认** / 16M / 40M
  - 帧率上限：15 / **30** / 60 fps
  - 画面上限：原始 / **1080p** / 720p（设备端长边缩放，只缩不放）
- **窗口置顶**（顶栏图钉图标钮）：投屏窗默认是**普通窗口**——不占前台，其他应用的窗口可以盖过来；想边操作其他软件边看设备画面时，点一下图钉切**恒置顶**（图标变主题色），再点一下切回。置顶档随窗会话级，下次开窗回默认普通窗；窗被盖住找不到时，用投屏行卡的「聚焦窗口」钮一键带回前台
- **停止投屏**：窗内「停止投屏」钮，或直接**关窗**（关窗即停投）

### 性能

「开始采样」对当前设备持续读 **CPU / 内存 / FPS / 电池 / 温度** 五域读数并画曲线：

- 读数行实时刷新；FPS 是**全屏合成帧率**（系统各显示层合成后的帧率，非单应用帧率）
- **多设备批量采样**（多台设备在台时出现「批量采样」区）：勾选目标设备集（进入批量态预勾选当前选定台）→ 点「目标 N 台」开始——每台设备独立会话，**多曲线同屏**：每台一色，CPU 实线/内存同色系/FPS 点列；单台可单独停（「停止 <设备尾号> 的采样」）
- 曲线「清空曲线」清画布；切走子签/页面采样不断，回来接着看
- **导出 CSV**：采样中或停止后的历史曲线都可点「导出 CSV」——epoch 毫秒时间戳 + 三域读数落 **`~/Documents/Toolbelt/perf/`**（`perf-<时间戳>.csv`，失败拍空字段如实呈现）；可「送飞书」直发
- 某域读取失败（ROM 不支持等）只标该域错误，不拖垮整拍

### 按键遥控

注入单个按键或自定义 keycode：常用按键胶囊（上/下/左/右等）点按即注入、**长按连发**；「自定义 keycode」框支持键值数字或常量名（如 `24` / `volume`）查询后注入；多设备时勾选目标集可**批量注入**（逐台回执聚合展示，失败的单独列出）。

## 文件子签（设备文件浏览）

设备侧文件浏览器（adb shell 语义，浏览 /sdcard 等任意可读目录）：

- **浏览**：点目录进入、点面包屑/「返回上级」回退；目录导航栈切子签不丢
- **按名称过滤**：右上搜索框纯显示层过滤（如 `log`、`Movies`），不发起设备请求；条目显示类型图标、大小（B/KB/MB/GB 人话）与修改时间
- **symlink 条目**：行可点——点击自动解析真值分派：真值目录直接进入、真值文件给回执引导（可拉取）、断链给人话回执（`/sdcard` 这类尾斜杠路径按原样处理，不做静默改写）
- **拉取到本地**（行尾下载图标）：文件单拉；**目录递归拉取**（整目录带回，进度显示期望大小）；symlink 先判真值再放行
- **同名避让**：拉取落盘撞名时自动 `-N` 序号避让（`log.txt` → `log-1.txt`，后缀插在扩展名前）；同源（同设备同目录）重拉刷新既有产物不堆副本，异源（异设备/异目录）同名各自避让并存
- **图片预览**：图片后缀条目可「拉取并预览图片」——拉回后应用内直接看（魔数识别 PNG/JPEG/GIF/WebP，按高度上限缩放）
- **推送文件**：把本机文件推上设备（选择文件后推到当前目录）；**目标已有同名文件时弹确认对话框**（「覆盖后设备侧原文件不可恢复」）——取消则零动作，绝不静默覆盖
- **拉回产物行动作**：每次拉取的产物行保留在面板（最近在上，会话级）：文件产物可「查看」（应用内日志查看器）、「**送分析**」（按后缀衔接下游工具——.xlog 送解密、日志送过滤等）、「打开所在文件夹」；目录产物无查看/衔接钮（目录名后缀不承载文件语义）；产物被外部删除后点动作给人话回执

## 应用子签（设备应用）

设备侧包列表（`pm list packages` 语义）：

- **列表与过滤**：全部包/仅系统包/仅非系统包三态档；「按包名过滤」搜索框（如 `com.example.app`）；显示版本名/版本号/安装时间/更新时间/代码路径
- **排序档**：按包名（默认原序）/ 按 CPU / 按内存——后两档用性能采样的运行态读数降序，无读数的包沉底
- **运行态徽标**：正在运行的应用显示进程数（多进程应用标 `×N`）与内存占用（配合性能采样读数）
- **应用详情**：点包名看详情卡（权限清单、APK 路径等）；可「**导出 APK**」把安装包拉回本机（多 split 逐文件导出，有进度）
- **快照对比**：点「**保存快照**」定格当前包列表（含来源设备与时刻）——之后装/卸/升级后再点「**对比**」得三分类结果：**新增包 / 消失包 / 版本变更**（vCode 成对呈现）；快照来自另一台设备时弹「跨设备对比确认」（不同设备的预装差异对比场景，确认后继续，结果标注两侧设备）。快照是会话级内存快照不落盘——重开应用后需重新保存定格
- **禁用 / 启用**：详情卡可对应用执行禁用/启用（`pm disable/enable` 语义）——系统应用的禁用/启用都有**红色确认对话框**（「禁用系统应用可能导致设备功能异常」），防误触

## 布局子签（窗口布局）

设备当前界面的控件层级（主源 = 全窗口视图抓取，多窗口 + View 内部属性；该命令不可用的 ROM 显式降级 uiautomator dump 并人话标注能力差）：

- 点「**抓取可见窗口层级**」拿当前界面树（设备界面节点可上千，抓取是数秒级显式动作，不随进页自动刷）；显示节点总数与抓取目标设备；全窗口视图源可下拉切换查看各可见窗口
- **双栏工作区**（窄窗口纵向回落）：左栏**层级线框图**——按各节点的 bounds 画矩形（与树共享同一份展开/过滤/选中状态，深度折叠同步零漂移）；滚轮缩放、左键拖拽平移、双击重置视口；**点框选中**（重叠处点到的是最内层控件）；不可见（INVISIBLE/GONE）节点画淡化框仍可点选（排查「屏上为什么没这个控件」）。右栏**层级树**：默认展开前两层，逐层点开/收起；节点行显示 text/resource-id/class 与能力徽标；两侧点选互相同步定位（选中行不在视口时自动滚到）
- **搜索直达**：过滤框按 text / resource-id / class 匹配——命中节点的祖先路径自动展开（线框图与树都只画命中子树），无匹配给提示
- **详情卡**（点节点/点框展开）：class、id、bounds `[l,t][r,b]`、尺寸、全局中心、标记；全窗口视图源另有 **View 内部属性组**（measured/drawing/scroll/padding 等全量标量属性）与**嵌套属性组**（流内实有的 layoutParams 等嵌套 map 组，有则呈现）
- **按需补抓文本**（View 内部源专属：该源无文本内容）：详情卡点「**按需补抓文本**」——按节点 bounds 与聚焦窗口 a11y 树做匹配拿文本（约数秒，仅覆盖当前聚焦窗口，可中途停止）；快照来源不明/抓取进行中置灰并说明原因
- **投屏点亮**：详情卡点「**投屏点亮**」——向设备画面上该控件的**中心点注入一次点击**（跨屏操作树里看到的控件）。门控：投屏须正在出画且与快照同设备（否则给人话拒绝：投屏未运行/连接中/已停止/快照来自另一台设备各有指路）；点击按**布局快照坐标**注入——dump 后界面已变会点错位，重新抓取即刷新（回执如实标注）
- **帧上高亮框联动**：投屏出画且与快照同设备时，选中的节点会在**投屏画面上画一个高亮框**（图工具行的链形钮可关——关后选中不上帧）；非 Streaming/串号失配/离开布局子签时帧上自动无框

## 转无线（一键）

设备栏「**转无线**」钮（**设备观测页与 Shell 工具页两处都有**——设备栏是共享件）：把「查设备 IP → `adb tcpip 5555` → `adb connect <ip>:5555`」三步压成一钮，拔掉 USB 线后走 WiFi 继续调试：

- 先探后切：IP 探测失败时不动 tcpip（USB 通道完好，不会把设备弄失联）
- 成功回执带无线新串号（`<ip>:5555`），设备检测列表直接可见
- IP 探测不出来（部分定制 ROM）时回执指路去 Shell 工具页「连接无线设备」手动命令面兜底
- 连接中连点防抖；同设备会出现 USB 串号与无线串号并存（检测面原样呈现，不去重）

## 注意

- 一切采集的前置：设备栏出现你的设备（没配 adb 路径先去设置页配）
- 多设备在台时，各子签的操作都指向**设备栏选定的那台**（文件浏览/应用/布局/抓取目标）；批量采样与批量按键是显式勾选集例外
- 复现记录三通道各管各的产物：日志落 `~/Documents/Toolbelt/logcat/`、性能 CSV 落 `~/Documents/Toolbelt/perf/`、录像落 `~/Documents/Toolbelt/recordings/`、快照落 `~/Documents/Toolbelt/snapshots/`
- 投屏画质档位只在会话起点生效；改档后重开投屏才应用（档位入口在独立窗顶栏「画质」弹层）
- logcat 抓取与性能采样切页不断（包括去别的空间页）；投屏切页同样不断，但独立窗**关窗即停止投屏**——停止面 = 窗内「停止投屏」钮 / 关窗 / 复现记录行停止
