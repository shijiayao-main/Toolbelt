# MCP 服务

一句话：把本工具的日志分析工具与 agent 能力经 MCP 协议开放出去——Claude Code、IDE 等外部 AI 工具连上后，就能在它们里面直接调用这台电脑上的工具。

## 什么时候用

- 在 Claude Code / IDE 等支持 MCP 的工具里，想直接指挥本工具跑日志根因研判、知识蒸馏、文件取证
- 想让其他 AI 应用用上本工具的本地分析能力，而不用来回搬文件

## 怎么用

### 1. 进入页面

点 dock 系统区的「MCP 服务」图标。

### 2. 开启服务

1. 「服务配置」区打开「开启 MCP 服务」开关——服务只绑定本机 127.0.0.1，不对外网开放；App 退出自动停止
2. 开启过程约几秒（开关旁会提示等待端口就绪），成功后「服务状态」卡显示「运行中」徽章，「端点」行给出可复制的端点 URL（默认端口 8765，形如 `http://127.0.0.1:8765/mcp`）
3. 启动失败会有红色横幅明示原因（如「端口被占用，请修改端口」）——换端口后重新打开开关

### 3. 接入外部工具

服务运行中，状态卡会给出「接入示例（运行中展示，点击复制）」两行，点行尾复制按钮即可：

- 命令行接入：`claude mcp add toolbelt --transport http http://127.0.0.1:8765/mcp`
- 配置文件接入：对应的 mcpServers JSON 片段

粘到对应工具里就连上了。状态卡下方还有一句说明：外部 MCP client（Claude Code / IDE / MCP Inspector）连接上述端点即可调用本地工具与 agent 会话。

### 4. 修改端口

1. 「端口」框改号后提交（合法域 1024..65535，默认 8765）
2. 运行中改端口会即时重启服务；若有在途 agent 会话，会先弹「重启 MCP 服务」确认框：「端口变更将重启服务并中止全部 N 个在途 agent 会话，外部 client 需按新端口重连。」——点「重启」继续，点「取消」维持原端口

### 5. 看外放了哪些工具

「外放工具清单」卡按族列出外部可调用的全部工具：

- 「fs.extended 取证」「knowledge 检索」「log 管线」：本地文件取证与日志处理工具
- 「agent 会话」：可从外部发起的长流程 agent（日志根因研判、知识蒸馏、进度查询）
- 带「写盘」徽标的工具会写文件，外部调用时留意

### 6. 看运行状态与日志

- 「在途 agent 会话」行实时显示外部发起、还没跑完的会话数（形如「0 / 10」）；到 10 个上限后外部新起的会话会被拒绝
- 「服务日志」卡记录开启 / 关闭 / 端口变更 / 端点就绪等事件（环形保留最近 200 行）

## 注意

- 服务默认不开，每次要用先来本页打开开关；开关与端口设置跨重启保留
- 只监听本机 127.0.0.1——其他电脑连不上是预期行为
- agent 会话类工具（根因研判 / 知识蒸馏）依赖模型服务：先在「AI 设置」配好，外部调用才出结果

## 常见问题

- **外部工具连不上？** 确认本页显示「运行中」、外部配置的 URL 与「端点」行完全一致；改过端口的话外部要按新端口重连
- **开启时提示端口被占用？** 「端口」框换个号（1024..65535 内）提交，再打开开关
- **外部跑的研判会话没结果？** 先在「AI 设置」确认模型服务可用；进度与结果由外部工具用会话查询工具取回
