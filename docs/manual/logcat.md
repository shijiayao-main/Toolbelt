# logcat 实时抓取

一句话：复现问题时在工具箱里直接抓设备现场日志——不用开终端，抓完的文件还能一键送进「XLog 解密」「Tag 过滤」或工作台分析。

入口：dock「设备观测」空间（第六个空间图标，快捷键 **Ctrl+6**）。

## 什么时候用

- 问题复现是偶发的，得开着实时日志等它出现
- 想边抓日志边盯屏，复现出现的那一下直接「标记」住位置
- 抓完不想手动把文件拖来拖去——一键送 Tag 过滤 / 送工作台让 AI 研判 / 发飞书

## 怎么用

### 第一次使用

1. 不用装 adb——应用自带。想确认是否可用，可去「设置」页（Ctrl+,）点「检测可用性」看版本号
2. 打开「设备观测」页（Ctrl+6），顶部设备栏出现你的设备即连接正常

### 抓一次现场日志

设备栏正下方有「logcat 实时抓取」面板（默认收起，点标题行展开）：

1. 在上方设备栏选中目标设备
2. 展开面板，可选填**过滤查询**和「级别」筛选（不填就全量抓）；查询语法见[下节](#过滤查询语法)，无算子的裸词自动按旧语义（tag 多词包含）处理，不用担心写法；过滤条件会记住上次的，重开应用不用重填；**抓取进行中也可以随时改过滤**——改动即时生效且只影响后续到达的行（已显示和已落盘的行保留原样），不用停止重抓
3. 点「开始抓取」，下方实时滚动显示捕获内容（界面只保留最近一段，**文件里是全量**；超出保留上限时面板会提示「已丢弃最早 N 行（仅影响回看，落盘完整）」——往回滚找不到开头几行是正常的，不是没抓到）；盯屏时点「清屏」可把滚动窗清成空白——**只清显示不清落盘**（文件内容和已捕获行数都不变），配合改过滤就是「改过滤 → 清屏 → 只看新行」；**复现出现的那一下点「标记」**，把当前位置记成锚点（多点以最后一次为准）；不想盯屏可以用[武装捕获](#武装捕获等待复现的自动收网)让命中自动标记
4. 点「停止并落盘」，文件保存为 `~/Documents/Toolbelt/logcat/logcat-<时间戳>.txt`，面板会显示完整路径——点旁边的「送往 Tag 过滤」一次点击进过滤（命令面板参数直填态已预填文件路径，补个 Tag 正则就能跑）；点「送工作台分析」**直接跳日志工作台**预填产物路径（标记过则自动聚焦复现时刻——问题时间点一并预填），让 AI 全链研判（复现问题 → 研判的最短路径）；点「送飞书」把刚抓的文件一键发进飞书接收会话（前置：飞书桥接在跑——没跑时按钮置灰并提示原因）；点「查看」**不出应用**直接核对刚抓到的日志（行号跳转、级别着色、滚动续读）——抓取中点过「标记」的话**直接定位到标记时刻**，不用肉眼回找；或「打开所在文件夹」拖进其他工具

## 过滤查询语法

查询框里除了直接写 tag 词，还支持一套查询语法（输入框占位提示：`过滤查询：裸词 = tag 包含；支持 tag: level: & | - ( ) ~/正则/`）：

| 写法 | 语义 |
|------|------|
| `tag:词` | tag 包含该词（子串命中、忽略大小写） |
| `tag:~/正则/` | tag 按正则子串命中（大小写敏感；要忽略大小写在正则前加 `(?i)`；正则里要匹配 `/` 字符写 `[/]`） |
| `level:档` | 级别严重度 **≥** 该档；档写单字母或全名（V/D/I/W/E/F，大小写不敏感） |
| `msg:词` | 消息体包含该词（子串命中、忽略大小写）；消息体指「TAG: 」分隔符后的内容，tag 本身不在匹配范围 |
| `msg:~/正则/` | 消息体按正则子串命中（大小写敏感，同上） |
| 裸词 | 等价 `tag:词` 的简写 |
| `-项` | 排除：不满足该项才命中（如 `-tag:chatty`） |
| 项与项相邻并列或用 `&` | 都要命中（AND） |
| `a \| b` | 命中其一即可（OR） |
| `( )` | 分组强制优先级；优先级为排除 > 与 > 或 |

示例：

```text
level:E                                  # 只看 E 以上（含 E/F）
tag:bt msg:timeout                       # tag 含 bt 且消息体含 timeout
(tag:audio | tag:media) -msg:skip        # 音频或媒体 tag，排除消息体含 skip 的行
tag:~/AN[Rr]/                            # tag 正则命中
```

- 不含任何算子（`&` `|` `(` `)` `:`）的裸串自动回退旧语义：空格/逗号分隔多词，任一词命中 tag 即保留（与历史行为逐字一致）
- 「级别」chips 与查询串**同时生效**（两者取交集）；查询里写了 `level:` 时以更严的档为准
- 语法写错不会静默：输入框立即标红并给出人话错误（如「level: 档位无效（可用 V/D/I/W/E/F 或级别全名）」），引擎**保持上一份有效过滤**继续抓，改对即恢复
- 输入框下方有输入提示：空内容时显示算子概览；刚敲完 `tag:` / `level:` / `msg:` 时提示该算子的值域

## 武装捕获（等待复现的自动收网）

偶发问题的复现时刻不好掐——武装捕获让你**埋伏一个特征正则，命中行自动标记锚点**，复现瞬间不用手点「标记」：

1. 抓取进行中，在「特征正则（武装捕获：命中自动标记）」输入框填特征（是对**整行日志**做包含匹配的正则——和过滤查询是两条独立通道：过滤挡掉的行武装照样看得见，落盘口径零变化）
2. 点「武装」进入等待态（状态行显示「已武装 · 等待特征命中」）；命中那一刻自动标记锚点并弹提示「特征已命中，标记 @ 时间」，之后停止抓取点「查看」直达命中处
3. 想撤就点「解除武装」；已武装时特征输入框和预设锁定，改特征先解除

**常见特征预设**：「常见特征：」一行提供四个高频特征，点击只**填入**输入框（可改后再武装，不会自动开始）：

| 预设 | 特征正则 |
|------|---------|
| Java 崩溃 | `FATAL EXCEPTION` |
| ANR | `ANR in ` |
| native 崩溃 | `SIGSEGV\|Fatal signal` |
| 应用被杀 | `am_kill\|Force stopping` |

**武装后自动停止**：「武装后自动停止：」一档可选延迟——武装时刻起倒计时到点自动停止抓取并落盘（时间盒埋伏：布好雷区走人，到点回来产物已封口）。档位：不延迟（默认）/ 30 秒 / 1 分钟 / 5 分钟。已武装时改档锁定，先解除再改。

## 控制台显示：堆栈折叠与崩溃高亮

实时滚动台对崩溃堆栈做了两件渲染层的优化（引擎与落盘文件零触碰，文件里仍是全量原始行）：

- **堆栈折叠**：连续 5 行以上的 `at` 堆栈帧行默认折叠成一组，只显示第一帧加一行「… 崩溃堆栈共 N 帧，点击展开」——点一下展开全部帧；两三帧的短栈不折叠
- **崩溃高亮**：堆栈帧行着错误深色（与折叠同一套行判定，无行数门槛——不折叠的短帧行串同样着色），滚动时「哪里炸了」一眼可见

## 注意

- 过滤条件在抓取进行中也可以随时改——改动即时生效，只影响后续到达的行，已显示与已落盘的行保留原样，不用停止重抓
- 抓取中点「清屏」只清滚动显示窗（清显示不清落盘，文件与已捕获行数不变），后续命中行照常滚动显示；清屏不清溢出计数，溢出提示照常呈现
- 武装正则是对整行做匹配的独立判定通道——查询语法（过滤）只决定哪些行落盘，**永远不会触发武装**；两通道不合流
- 特征正则与延迟档是当次盯屏的临场设置，不持久化（重启后回默认：空特征、不延迟）；过滤条件才会记住
- 没检测到设备或 adb 路径不对时点开始会给指路提示（不会静默不动）
- 设了过滤但一条都没命中时，停止后提示「共 0 行」——文件为空
- 设了过滤时格式不标准的行会被丢弃（只保留能确认命中的行）
- 抓取切页不中断：引擎在后台继续抓，回本页或去别的页都不影响；停不停由你点「停止并落盘」说了算

## 常见问题

- **抓完的文件在哪？** `~/Documents/Toolbelt/logcat/` 目录下，文件名带抓取时间；同一秒多次停止会自动加序号后缀，不会互相覆盖
- **为什么面板里找不到开头几行？** 界面滚动窗只保留最近一段，超出会提示「已丢弃最早 N 行」——**落盘文件是全量的**，以文件为准
- **武装了但没反应？** 先确认状态行是「已武装 · 等待特征命中」；特征正则是对整行做包含匹配，写太窄可能永远等不到——可先用「解除武装」撤回，放宽特征再武装；命中但行没有时间戳时会提示「未能自动标记」
