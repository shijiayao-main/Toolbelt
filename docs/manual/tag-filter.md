# Tag 过滤

一句话：按业务 Tag 的正则表达式从大日志里提取出你关注的模块日志块。

## 什么时候用

- 一份日志混了几十个模块的输出，只想看某个模块（如 `MyTag`）相关的日志块
- 排查问题时需要把某业务模块的完整上下文（块级提取，不是只留命中行）单独拎出来

## 怎么用

1. 进入页面：点左侧 dock 的「工具」图标（快捷键 Ctrl+5），切到「Tag 过滤」子签；或按 Ctrl+K 打开命令面板，输「Tag 过滤」直达
2. 填两个输入框：
   - 「Tag 正则」：`输入 tag 正则表达式，例如: MyTag`
   - 「输出标记」：`用于输出文件命名，如 MyTag`
3. 把 `.txt` 日志拖进投放区（「拖入或点击选择 .txt 日志文件（支持多选与目录）」），「松开以开始过滤」——**整目录也可以直接拖**（如解压出的 `_extracted` 目录），会自动找出里面的 .txt 逐个建卡
4. 「过滤任务」列表里看进度（还没任务时会显示「还没有过滤任务」的空态引导），完成后输出文件按你填的「输出标记」命名

支持同时拖入多个文件批量过滤。

### 正则预演（写正则不用瞎试）

拖入过文件后，参数区底部会出现「正则预演（仅前 2000 行，非全量）」：显示最近拖入文件的**命中块数 / 完整块数**和首个命中块的前几行——**改一下正则，预演立刻跟着变**，不用整轮跑完才知道抓没抓对。正则为空或语法有误时预演区自动隐藏。推荐用法：**先拖文件（哪怕被拦下也会记住），再边改正则边看预演**，预演看着对了再重新拖入跑全量。

### 看分布（先看分布再决定过滤哪个 Tag）

对几万行的日志不知道该过滤哪个 Tag？点「看分布」——对最近拖入的文件全量扫描，几秒内给出：**Top 10 Tag 频次表**（哪个模块话最多一目了然）、**级别计数**（V/D/I/W/E/F 各多少条，ERROR 多不多）、**首末时间戳跨度**（这份日志覆盖多长时间）。解析不出的块会归入「未识别」差值。

**Tag 频次行可以直接点**：点哪个 Tag，它就以字面值（含特殊字符自动转义）填进「Tag 正则」框并**覆盖**你已填的正则——预演随即自动刷新，看着对了直接跑全量。「看分布 → 点 Tag → 跑过滤」三步闭环，不用手抄。

**导出/送飞书**：点「导出 Markdown」把统计结果存成 `~/Documents/Toolbelt/reports/stats-<时间>.md`（可直接贴工单/发同事）；点「送飞书」则自动重新导出并把这份文件直接发进飞书桥接的接收会话——前提是**飞书桥接正在运行**，没在跑时按钮会置灰并提示先去「飞书桥接」页启动桥接。

### 任务卡上的操作

- 完成的任务卡带「深度分析」和「打开文件夹」按钮：点「深度分析」把产物直接送进「工作台」开始 AI 深度分析；点「打开文件夹」跳到产物所在目录
- 任务卡行尾有「⋯」按钮（右键任务卡同款菜单）：进行中的任务可「取消任务」；失败的任务可「重试」或「打开文件夹」
- 成功的任务卡菜单还有**「查看」**：在应用内直接打开产物文件——按行号跳转、级别着色、滚动到底自动续读，不用出应用（产物是目录时该入口自动隐藏）
- 成功的任务卡菜单还有**「送飞书」**：把产物文件直接发进飞书桥接的接收会话，不用手动搬运（前提是飞书桥接正在运行，没在跑时该菜单项置灰；产物是目录时不出现）
- 「清空列表」清掉的任务可以撤销——清完底部会弹出撤销提示，点一下就全恢复

## 注意

- 输入文件要求 `.txt`——加密的 `.xlog` / `.alog` 需先切到同页的「XLog 解密」子签解密
- 「Tag 正则」「输出标记」都必填——漏了会在拖入时被拦下并提示「Tag 正则不能为空」或「输出标记不能为空」
- 正则写错（如未闭合括号）不用等拖入——输入框会即时标红提示「Tag 正则语法有误」并给出原因，修正后重新拖入（已输入内容保留）
- 提取是**块级**的：命中 Tag 的整个日志块（含块内其他行）都会保留，保证上下文完整
- **预演只是前 2000 行的样本**：大文件后面的内容没算进去，预演命中 ≠ 全文件命中；文件超长时最后一个不完整块会显示「截断尾块已跳过」
- 输出文件已存在时会弹「产物已存在」确认框：点「覆盖重跑」清掉旧产物重跑，点「取消」则旧产物原样保留
- 有任务处理中时投放区会拒收新文件，等当前批次跑完再拖

## 常见问题

- **过滤结果为空？** 大概率 Tag 正则没命中——日志里实际 Tag 与你填的不一致，先用文本编辑器搜一下真实 Tag 拼写
- **输出文件在哪？** 与源文件同目录，文件名含你填的「输出标记」，点任务卡上的「打开文件夹」可直接到达
- **「深度分析」点了没反应？** 深度分析依赖 AI 能力——先去「AI 设置」把模型服务配好；「工作台」页会带预填产物等待你开始
