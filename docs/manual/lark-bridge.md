# 飞书桥接

一句话：把飞书里的消息接到你电脑上的 AI 助手——在飞书发指令，电脑上的 agent 干活，结果发回飞书。

## 什么时候用

- 人不在电脑前，想在飞书（手机/网页）上让 AI 帮你查日志、跑分析
- 群里有人发了日志文件，想让机器人当场分析
- 想知道家里/公司那台跑桥接的电脑现在还连着没有

## 第一次配置（快速上手）

新用户打开配置页只会看到**一张「快速上手」卡**：应用凭据、工作区等必填项，每填好一块，顶部的「凭据 / 工作区」徽章就亮一个——**两个徽章全亮后，这张卡会自动变成正常的完整配置页**，其余几十项按场景收进分区里，不用做任何切换操作。驾驶舱快速开始的「去填写」按钮会直接跳到这张卡并帮你把光标定位到第一个还没填的框。

1. **先去「AI 设置」页配好模型服务**（Base URL / API Key / 模型 ID）——机器人靠它思考；驾驶舱快速开始的第 0 步会检查这个，没配的话点「去配置 AI」直达
2. 回到 App，点左侧 dock 的「飞书桥接」图标（快捷键 Ctrl+4）进页，点驾驶舱「扫码建应用」，用飞书扫码——应用凭据自动回填
3. 飞书后台还需核对（机器人能力的开启、事件订阅切「使用长连接」等，页面里的引导卡片有逐步说明）
4. 「工作区根目录」选一个 agent 可用的目录
5. （推荐）在「信任用户」里填你自己的 openId——不知道 openId？启动后在飞书发 `/whoami`，机器人回你。**不填也能用**：任何人都能和机器人对话，只是高风险操作（写文件、跑构建、改系统配置、删文件）都会先弹确认卡等你点「允许」
6. 点「启动」。驾驶舱出现「运行中 · 已连接」即成功

**配置页里的东西太多找不到？** 顶部有搜索框：输入「超时」之类的关键词直接定位，输 `@modified` 只看你改过的项、输 `@restart` 只看需要重启才生效的项；改过的项左侧有蓝条标记，鼠标悬停会出现「恢复默认」。

## 怎么用

### 查看机器人是否在线

给机器人发「**状态**」（或 `/status`），立刻收到回信：

- 🟢 在线：连接状态、连接自几点几分、运行了多久、累计处理多少条消息、当前几个 agent 在跑
- 🟡 在线 · 重连中：网络抖了在自动重连，期间消息可能延迟
- **完全没有回复 = 机器人主机没开机、或桥接没启动**——发消息永远显示成功，但没人接

机器人只在它活着的时候说话，所以「发状态没回音」本身就是离线信号。

### 让机器人分析文件

1. 直接把文件（.log/.zip/.xlog 等）发到会话里，机器人回一句「已收到文件」
2. **引用回复**那条文件消息，直接说你要什么（比如「分析这个日志」）
3. 机器人下载文件、解包/解密（按配置）、交给 agent 分析，结果发回会话

同一个文件引用第二次不会重新下载；别人发过一模一样的文件也不会占双份磁盘。改了配置再引用时，解包/解密会按新配置自动重跑。

### 高风险操作要你先确认

机器人要执行有风险的操作（比如删文件、改系统配置）时，不会直接干，而是先发一张「**需要你的确认**」的卡片：

1. 卡片上写明风险等级（如「高风险操作」）、要用的工具和参数，点「允许」放行、点「拒绝」拦下
2. 也可以不点按钮，直接回复「确认 <编号>」或「拒绝 <编号>」——卡片底部就印着这句提示和那串短码，照着打字就行（手机上按钮抽风时的保底通道）
3. 裁决后**原来的确认卡会变成「已批准」或「已拒绝」的样子，按钮消失**，末尾还带一行「单据：cf-xxxx」短码方便事后对账——过会儿再翻聊天记录也不会误点旧按钮
4. 只有发起请求的人自己能裁决，群里其他人点了没用（防替答）

App 驾驶舱里也能看到等待中的确认：有卡片在等你点时，驾驶舱会出现「待你确认」区块，显示工具名、发起人、**剩余时间倒计时**和已读人数——看到它在跳，说明有件事等你拿主意。

没在规定时间内答复（默认 60 秒，最长可配 1 小时），会被当作拒绝处理——机器人不会一直等你。

**想让自己不再逐次点确认？** 把 openId 填进配置页的「**信任用户**」列表：名单内的人做高风险操作（写文件、跑构建、改系统配置、系统修复、服务启停）时**直接执行、不再弹卡**。名单外的人遇到「越界」操作（删工作区之外的文件、改系统配置、跑系统服务、在别的群建群）会被**直接拒绝**，连确认卡都不弹——不给陌生人自己批准自己破坏性操作的机会。不在名单里的人**连写文件、跑构建、改系统配置这些域都进不去**（直接回一句「仅限信任用户」，不发卡）——这正是名单的意义：只放你自己人进来干活。

### 机器人反过来问你（信息补全）

机器人缺关键信息、干不下去的时候，不会瞎猜，而是发一张「**机器人需要你的补充**」卡片问你。比如你让它改工作区里的某个配置文件但没说改成什么，它会把问题列在卡片上。

**怎么回答：直接引用回复那张卡片**，把补充内容写在回复里就行——不用学任何格式。单选类问题卡片上也会带选项按钮，直接点也行。一次把所有问题都答完最好；实在没有就回复「跳过」，机器人会基于现状继续、并在结果里说明它做了哪些假设。一直不回的话它会等一段时间后自己按「跳过」继续。

### 日常指令

| 发什么 | 得到什么 |
|--------|---------|
| `状态` / `/status` | 桥接在线状态真值 |
| `ping` | 链路自证（pong） |
| `/commands` | 全部可用指令清单 |
| `/help` | 简要使用说明 |
| `/whoami` | 你的 openId 和会话 ID |
| `新对话` | 清空机器人的对话记忆，从零开始聊 |
| `停止` | 停掉正在跑的任务 |

### 本地 AI 接管（默认形态）

机器人由本地 AI（大脑）接管全部消息——**不需要开任何开关**，也不需要 `ai` 前缀，直接说话就行：

- **没命中固定指令的消息**（闲聊、提问、复杂任务）统一交给本地 AI 判断——它自己决定是直接答复、发文件/卡片/图片，还是调本地工具干活（解密/过滤/写文件/跑构建/git 查询）
- **深度分析会收到完整交付**：分析做完后，机器人会把**分析结论卡片和报告文件**都发回会话
- **凭据类文件发不出去**（安全限制，有意为之）：私钥（`id_rsa` 等）、证书（`.pem`/`.key`）、`.env` 配置文件、以及桥接和本工具自己的配置数据，一律不允许作为文件发出。让它发这类文件时，机器人会回一句「出于安全考虑不允许外发」并改用其他方式交付
- 想让机器人**完全不发文件**：在配置页展开「任务行为与限额」分区，把「产物回传」开关关掉，此后它只用文字和卡片答复
- 固定指令（`状态`、`/help` 等）**照旧秒回**，不走 AI
- 需要在「AI 设置」页配置模型服务（Base URL / API Key / 模型 ID）；**桥接运行中去配置也行**——配好一秒内自动激活，不用重启
- 想让机器人带人设/口气回复？两个地方都能调：配置页「机器人主卡」里的「机器人人设」填一段身份描述（如「你是日志分析助理小析」）；「AI 设置」页的「性格模式」选整体语气档（温和友好/简洁精炼/专业严谨/猫娘/自定义）、「安全约束」选约束档——影响机器人的全部回复（详见 [AI 设置](ai-settings.md)）

### 机器人的能力分级

机器人的本领分两级——**一级是飞书里的原生操作**（发消息/图片/表情、话题回复、撤回自己刚发错的消息），**二级是本地文件处理**（解密日志、过滤、分割、解压——分析结果再经一级通道发回给你）：

- **直接可用的**（一级，零配置）：发图片产物、给消息点表情、群话题内回复、撤回机器人自己刚发的消息
- **跨会话能力**（已启用，只差飞书后台授权）：拉当前会话的历史消息、查群信息/成员、建群、查用户资料、读知识库/文档链接。**不用在本地开任何开关**——唯一门槛是去**飞书后台开通对应的权限 scope 并发版**。配置页「能力中心」卡里列了这 6 项以及各自需要的权限，每行有「复制权限」「打开飞书后台」两个按钮帮你做；点「验证」机器人会用只读方式当场试一下通不通，绿了才算真开通——没开通时机器人会如实告知「能力不可用」，不会瞎猜
- **工作区能力**（已启用）：在工作区里**写文件**（每次写入都要你在确认卡上核对改动内容后放行）、**跑构建/测试**（gradle/maven/npm/pnpm 四选一，每次执行也先确认）、**git 只读查询**（看提交历史/改动/谁改的这行）。只需在「连接与准入」分区把「工作区根目录」选好——三项能力都只在这个目录里干活，出不了圈。**本机诊断、设备观测、自检推送**同理：不再有开关，装了就能用
- **永远不会做的**（写死排除）：替你以个人身份操作飞书、撤回别人的消息、踢人、解散/改名群、全局搜索——机器人没有这些能力，谁配置都没用

### 引用文件直接下指令

**引用文件消息后直接说人话就行**，不用任何前缀：

1. 发文件到会话，机器人回「已收到文件」
2. **引用回复**那条文件消息，直接说「解密这个文件」或「按 Tag XXX 过滤一下」——不用任何前缀
3. 机器人会收到「提示中 / 调用工具」的过程反馈，然后：
   - **解密、按 Tag/时间过滤、按大小分割、解压、预览**这类活，本地 AI 直接用内置工具干（快，几秒出结果）
   - **深度分析**（比如「分析下为什么崩溃」）由本地 AI 综合用工具链完成——统计分布、下钻原文、跑构建测试、查 git 历史都在本地进行
4. 处理出的文件由机器人直接发回会话

### 解密设备加密日志（.xlog/.alog）的私钥配在哪

机器人解密 `.xlog`/`.alog` 加密日志需要私钥，**两个位置任配一处即可**：

- **桥接配置页 → 搜「私钥」或展开「文件消息」分区 → 「XLog 私钥」**：桥接自己的一份（推荐在这里配，纯命令行形态只认这里）
- **本应用「XLog 解密」页的私钥**：在桥接里留空时，**桌面 App 会自动复用这份私钥**（改了它 1 秒内生效，不用重启桥接）

两处都配了时以桥接配置里的为准；两处都没配时解密会提示缺私钥。**解密功能本身恒开启**，不再有开关——只要私钥在，收到加密日志就会自动解密。

### 改了需要重启的配置怎么办

改「应用凭据」「Agent 后端」这类标注「需重启」的配置并保存后，操作栏会出现一条黄字提示「以下改动需重启桥接才生效」——桥接正在运行时，提示条右侧有「**重启桥接**」按钮，点一下自动完成 停止 → 启动，不用手动点两次。

### 问机器人「这个工具怎么用」

机器人内置了本手册（随软件分发）：飞书里直接问它「这个工具能干什么」「XLog 解密怎么用」「飞书桥接怎么配置」，它会查手册后回答。手册随软件版本更新，重启后自动生效。

- 模型服务支持向量接口（/v1/embeddings）时自动用**语义检索**（效果最好）；不支持的网关会自动改用**本地关键词检索**，照样能答——什么都不用配
- 想用语义检索：在「AI 设置」页把「向量模型 ID」填上网关支持的向量模型名（如 text-embedding-3-small）

### App 里看运行状态

驾驶舱顶部的大图标区实时显示连接状态：已连接（含「连接自 HH:mm」）、重连中、已断开；下方运行状态卡有流水线计数、最近异常。这些数字现在每秒刷新，断网时会看到「长连接断开，自动重连中…」的提示。

## 注意

- **断线超过 30 分钟**：期间发的「状态」指令不会补答（平台重投上限），恢复后请重发一次
- **机器人靠你这台电脑活着**：电脑休眠、App 关闭、进程被杀，机器人就「消失」了——飞书侧不会报错，只是没人回
- 群聊里使用需要 @机器人（除非把群聊唤起模式改成「全部回复」）；**任何人都能和机器人对话**——想限制范围请去**飞书后台**把机器人的可用范围设成指定群/部门，比在本地维护名单可靠。高风险操作由「信任用户」名单与确认卡把关
- **模型服务没配置时**：发指令会收到「本地 AI 端点未配置」的明确提示（不是静默）——去「AI 设置」页配好即自动激活，无需重启

## 常见问题

- **发什么都没回复？** 先发「状态」确认机器人活着；活着但指令没回，用 `/commands` 核对指令名——你的自定义指令可能和内置指令撞名了（启动日志会有警告）
- **引用文件提示「本地未取回该消息」？** 可能消息已删除、或应用缺少消息读取权限；直接重新发一次文件最稳
- **重连中的消息会丢吗？** 30 分钟内的断线，飞书会自动重投补答；更长的断线期间发的消息不会补答
- **同一台电脑能开两个桥接吗？** 不能——同一个应用凭据全局只允许一个实例，第二个会被拒绝并在状态里写明原因
- **发消息半天没动静然后超时？** 检查「AI 设置」页的模型服务是否配好、模型是否正常响应；端点没配时机器人会直接回「端点未配置」的提示
- **机器人干解密/过滤这类活要很久吗？** 不用等——这类活由本地内置工具直接执行，飞书里能看到「调用工具」的过程反馈，一般几秒内完成；跑构建/测试这类长任务会实时显示进度，耗时以分钟计
