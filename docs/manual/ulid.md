# ULID 工具

一句话：生成 ULID（26 位、Crockford Base32、按毫秒时间戳排序的本地主键 / 链路标识），或把已有 ULID 粘进来反解出生成时间。

入口：「工具」页（dock 第 5 图标，快捷键 **Ctrl+5**）子签「**ULID 工具**」。

## 怎么用

### 生成

1. 「生成数量（1..100）」框填个数（默认 1）
2. 点「**生成**」——逐个列出，可一键「复制全部」（换行分隔）
3. 数量不是 1..100 的整数时给错误提示，按钮置灰

### 反解

「ULID 文本」框粘贴 26 位标准形态——显示：

- **时间戳（毫秒）** 与 **生成时间**（人类可读）
- **随机部分（hex）**
- **标准形态（大写）**（规范化形态，可复制）

非法串给人话错误，不静默。

## 注意

- 48 位毫秒时间戳 + 80 位加密强随机；**同一毫秒内多次生成不保证有序**（规格的单调性是可选项）——需要严格单调递增主键时自行在应用侧串行化
- 全部状态会话内有效，不持久化；本签是「工具」聚合页原生子签，命令面板没有对应的深入模式
