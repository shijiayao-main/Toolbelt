# 时间戳

一句话：时间戳与日期时间互相转换——粘贴一个，立即得到另一种。

## 什么时候用

- 看日志时对着 `1756790400123` 发懵，想立刻知道这是哪年哪月哪天几点
- 写脚本/日志时需要把「2026-09-02 15:30:00」转成毫秒或秒级时间戳
- 打日志做时间标记 / 报 bug 填时间点，需要随时取当前时间
- **分析耗时/间隔**：两个时间戳直接算差值（如启动耗时、两次事件间隔），不用转两次再心算
- **对账一列时间戳**：多行粘贴批量转换，行行对齐

## 怎么用

1. 进入页面：点左侧 dock 的「工具」图标（快捷键 Ctrl+5），切到「时间戳」子签；或按 Ctrl+K 打开命令面板，输「时间戳」直达
2. 页面顶部的「当前时间」卡默认收起成一行，直接显示当前秒级时间戳（每 0.5 秒跳动）+ 复制按钮；点标题行展开三行明细，每种格式各带复制按钮：
   - 「秒（10 位）」
   - 「毫秒（13 位）」
   - 「日志格式」
3. 在「双向转换」卡的输入框（`如 1756790400、1756790400123 或 2026-09-02 15:30:00`）粘贴任一格式——**方向自动识别**，粘贴后即时转换；按 **Enter 立即出结果**，不用等自动转换
4. 结果会按附注说明解析方向（「按秒解析 / 按毫秒解析 / 按日期时间解析」）并补一句相对时间（如「3 分钟前」）；旁边的复制按钮一键复制
5. 「输出格式」三档（日志 / 标准 / ISO-8601）切换即生效并**跨启动记住**
6. 输入框上方有「最近转换（cap 8）」记录条——点任意一条既回填输入框又立即转换，反复对时不用重输
7. 「区间差值」卡：在「起始」「结束」两个输入框各填一个时间戳或日期时间，立即显示「毫秒差值 · 人性化时长」——**两端格式可以不同**（纯数字秒/毫秒、标准/ISO 日期时间、从日志复制的 `2026-09-02_15:30:00.000` 下划线格式都能混着填）；结束早于起始会出负值并提示
8. 「批量转换」卡：把一列时间戳/日期时间整段粘进多行输入框，逐行按当前「输出格式」转换——输出带行号与输入行**严格对齐**，可整列复制（转不出的行留空占位，行数不乱）；与单行转换共用同一套格式档位

## 注意

- 秒级（10 位）与毫秒级（13 位）时间戳按位数自动识别，无需手动切换
- 日期时间支持常见日志格式，粘贴后自动转换，不需要点确认
- 收起 / 展开「当前时间」卡的选择会被记住，切走再回来保持原样
- **从日志复制的下划线格式**（`2026-09-02_15:30:00.000`）在单行、批量、差值里都直接认；时间部分不完整或非法时会**明确报错**（不会静默丢掉时间给你一个错误结果）

## 常见问题

- **转出来年份不对？** 检查粘贴的是否带了多余空格或单位（如 `ms` 后缀）——只贴纯数字或标准日期时间最稳
- **想换一种输出格式？** 用「输出格式」三档切换（日志 / 标准 / ISO-8601），选中的档会持久保存，下次打开还是它
