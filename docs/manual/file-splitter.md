# 文件分割

一句话：把超大 `.txt` 日志按指定大小切成多个分片文件，方便传输与逐段查看。

## 什么时候用

- 单个日志文件几百 MB，微信/邮件传不出去
- 日志工具打开大文件卡死，需要切成小片逐个看

## 怎么用

1. 进入页面：点左侧 dock 的「工具」图标（快捷键 Ctrl+5），切到「文件分割」子签；或按 Ctrl+K 打开命令面板，输「文件分割」直达
2. 「分割大小」填每个分片的上限（MB）——`每个分片不超过此大小（MB），需 ≥ 1`
3. 把 `.txt` 文件拖进投放区（「拖入或点击选择 .txt 文件（支持多选）」），「松开以分割文件」
4. 「分割任务」列表显示进度（还没任务时会显示「还没有分割任务」的空态引导），「将按设定大小分割为多个文件」

### 任务卡上的操作

- 完成的任务卡带「深度分析」和「打开文件夹」按钮：点「深度分析」把**全部分卷**一起送进「工作台」开始 AI 深度分析（多卷时提示会标明卷数）；点「打开文件夹」跳到产物所在目录
- 任务卡行尾有「⋯」按钮（右键任务卡同款菜单）：进行中的任务可「取消任务」；失败的任务可「重试」或「打开文件夹」
- 成功的任务卡菜单还有**「查看」**：在应用内直接打开产物文件——按行号跳转、级别着色、滚动到底自动续读，不用出应用（产物是目录时该入口自动隐藏）
- 「清空列表」清掉的任务可以撤销——清完底部会弹出撤销提示，点一下就全恢复

## 注意

- 只认 `.txt` 文本文件——加密日志先切到同页的「XLog 解密」子签解密
- 分片按行边界切（不会把一行日志从中间切断）
- 分片输出与源文件同目录，文件名带三位卷号后缀（`_000`、`_001` …），按序阅读即可
- 分割大小只接受 ≥ 1 的整数 MB
- 输出文件已存在时会弹「产物已存在」确认框：点「覆盖重跑」清掉旧产物重跑，点「取消」则旧产物原样保留
- 有任务处理中时投放区会拒收新文件，等当前批次跑完再拖

## 常见问题

- **分割大小填了小数？** 只接受 ≥ 1 的整数 MB
- **多文件批量？** 支持——同时拖入多个文件，每个文件独立分卷
