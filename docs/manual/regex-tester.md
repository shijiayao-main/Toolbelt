# 正则测试

一句话：写好一条正则，粘一段日志样本，即时看到命中区间高亮和分组捕获——调日志提取正则不用再开第三方网站。

入口：「工具」页（dock 第 5 图标，快捷键 **Ctrl+5**）子签「**正则测试**」。

## 怎么用

1. 「正则」框输入正则表达式——输入即校验，无效正则立即给出错误位置与修法提示（不静默）；语法是 **java.util.regex 方言**（与 Tag 过滤、代码里 `Regex()` 同一套）
2. 「样本文本」框粘贴待匹配文本（日志片段）
3. 看「命中预览」：命中区间在原文上**着色高亮**（零宽命中不着色，在分组视图单列标记）；正则无效时显示「正则无效，无可命中」
4. 看「分组捕获」：按命中逐条列出每处命中的序号、字符区间、命中原文，以及每个捕获分组的内容——未参与匹配的分组标「未参与」

## 注意

- 命中数上限 2000 处，超过会截断并明示「命中超过 2000 处已截断」；分组视图只展示前 100 处命中
- 不含捕获分组（没有括号）时分组视图会提示「正则不含捕获分组（...）」
- 全部状态会话内有效，不持久化——重开应用后正则和样本回到空
- 本签是「工具」聚合页原生子签，命令面板没有对应的深入模式；想到这一签，Ctrl+5 后点子签即可
