# AI 设置

一句话：在这里配置 AI 功能的「模型服务」，以及飞书机器人的性格与安全约束。

## 什么时候用

- 第一次使用飞书机器人前，先配好模型服务
- 想让飞书机器人换一种说话口吻（比如猫娘、专业严谨）
- 想改飞书机器人的安全约束（它能动什么、不能干什么）

## 怎么用

进入方式：点左侧 dock 系统区（侧栏下方）的「AI 设置」图标，或按 Ctrl+K 打开命令面板输「AI 设置」直达。

### 配置模型服务

1. 填「Base URL」：兼容 OpenAI 协议的网关地址（如 `https://api.deepseek.com/v1`）；留空用官方地址
2. 填「API Key」：你的密钥，明文保存在本机
3. 「模型 ID」：优先从下拉列表选——先点「测试连通性」通过后可点「拉取模型列表」；网关不支持列表接口时点「手动输入」直接填
4. 点「测试连通性」验证：通过会显示「已连通 <模型 ID>：回复预览」，失败会给出原因
5. 可选填「向量模型 ID」：飞书机器人知识库语义检索用；留空用默认（text-embedding-3-small），端点不支持时自动改用本地检索，**不用配置也能用**

### 开关 AI 工具

「启用 AI 工具」控制依赖模型服务的功能（如飞书机器人）能不能用：

1. 开关关闭时，依赖 AI 的功能会提示「AI 未开启」，工具页不受影响、照常可用
2. 拨开开关时会自动跑一次连通性探测，探测失败会拒绝开启并给出具体原因
3. 开启后即可正常使用

> 「万能解密」页已于 2026-09-19 移除：解密/解压用对应的工具页即可（两者离线可用，不需要 AI）。

**首次使用不用手动开**：只要把「Base URL / API Key / 模型 ID」配好并测试连通，开关会自动变为可用状态——因为开关的默认状态就看你有没有配好端点。当然，你也可以随时手动关掉它（关掉后不会因为配好了端点又自己打开）。

### 性格模式（飞书机器人）

「性格模式」卡决定飞书机器人回复的语气与风格：

1. 「模式」里选一档：温和友好（默认）/ 简洁精炼 / 专业严谨 / 猫娘 / 自定义
2. 内置档选中后显示只读预览——可以阅读、可以点复制按钮参考写法，但不能直接编辑
3. 选「自定义」出现文本框，自由描述你想要的语气与风格；留空 = 不加性格设定
4. 改动**一秒内生效**，不用重启——去飞书发条消息就能看到新口吻

注意作用范围：影响飞书机器人的**全部回复**的语气与风格。

### 安全约束（飞书机器人）

「安全约束」卡注入机器人提示词末尾的「不可违反」约束：

1. 「策略」里选：默认约束 / 自定义
2. 默认约束同样只读可复制——想改写就复制出来，切到「自定义」粘贴后修改
3. 自定义文本框逐条列出你的约束；留空 = 不注入安全段
4. 与性格模式一样，改动一秒内生效

## 注意

- 模型服务没配置时：飞书机器人会在飞书里回「端点未配置」的提示；本地工具页不受影响，照常可用
- 刚装好、还没配模型服务时，「启用 AI 工具」是关着的（这是正常的，不是坏了）——配好并测试连通后它自动可用
- 「请求超时（秒）」默认 60：单次 AI 调用的上限；网络慢的网关可以调大（5~600）
- 性格模式和安全约束**只对飞书机器人生效**

## 常见问题

- **测试连通性失败？** 先核对 Base URL 是否带对 `/v1`（不同网关惯例不同）、API Key 是否有效；页面会显示失败的具体原因
- **开关是灰的/打不开？** 先确认「模型服务」里的 API Key 与模型 ID 都填了；没填时开关处于关闭状态，填好并测试连通后即可拨开
- **机器人怎么还是老口吻？** 改完设置等一秒再发消息（配置每秒自动刷新）；还不对就发「新对话」清一下会话记忆再试
- **想看看默认安全约束写了什么？** 「安全约束」卡选「默认约束」就能看到全文，点复制可以拿去改写
