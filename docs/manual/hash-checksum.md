# 哈希校验

一句话：固件包/日志包核对——官网或同事给的是 MD5/SHA-256 校验值，本地算同样口径的哈希对上；CRC32 是传输校验单字口径。

入口：「工具」页（dock 第 5 图标，快捷键 **Ctrl+5**）子签「**哈希校验**」。

## 怎么用

### 算文本哈希

「待哈希文本」框粘贴字符串 / 日志片段——MD5 / SHA-1 / SHA-256 / CRC32 四算法**逐键即时重算**，每行算法名 + 小写十六进制值 + 复制钮（与 `md5sum` / `sha256sum` 输出同口径）。

### 算文件校验和

1. 「文件路径」框输入固件包 / 日志包绝对路径，或点「浏览」选文件
2. 点「**计算校验和**」——大文件 64KB 分块流式摘要（不整读入内存），结果显示四算法哈希值与实际读取字节数，逐值可复制
3. 路径为空 / 文件不存在 / 读取失败均给出人话错误，不静默

## 注意

- MD5 / SHA-1 是弱哈希，仅用于核对场景的对照口径，**不用于安全用途**
- 文本超过 8MB 字符拒绝计算并明示（超长文本逐键重算会阻塞界面）——大内容走文件校验和
- 输出长度恒定：MD5 32 位、SHA-1 40 位、SHA-256 64 位、CRC32 8 位（零填充）
- 全部状态会话内有效，不持久化；本签是「工具」聚合页原生子签，命令面板没有对应的深入模式
