# JSON 工具

一句话：把日志行里嵌的 JSON（信号 / 埋点 / 配置）粘进来——即时校验、格式化或压缩、再用 JSONPath 子集抽取想要的字段。

入口：「工具」页（dock 第 5 图标，快捷键 **Ctrl+5**）子签「**JSON 工具**」。

## 怎么用

### 格式化 / 压缩

1. 「JSON 文本」框粘贴 JSON——**粘贴即校验**：坏 JSON 给出行/列定位的人话错误；有效显示「JSON 有效」
2. 在「格式化 / 压缩」档位切换：格式化输出 2 空格缩进，压缩输出单行
3. 输出框旁有复制钮一键带走

### JSONPath 抽取

「JSONPath 查询」框输入查询（支持子集：`$` 根、`.name` 取键、`['name']` 取键、`[n]` 取下标、`.*` / `[*]` 通配——如 `$.data.items[0].name`、`$.items[*].id`），命中逐条列出：

- 「0 处命中（缺键 / 下标越界 / 类型不符均算零命中，非错误）」——查不到不是报错
- 超出上限会截断明示（命中上限 500 处，展示前 100 处）
- 语法子集之外的写法显式报错，不静默；JSON 本身没过校验时先修 JSON 再查询

## 注意

- 全部状态会话内有效，不持久化
- 命令面板的 Smart Detection 检测到剪贴板里是 JSON 时，可一键跳到本签并预填输入框（见 [Smart Detection](index.md#怎么找功能界面心智)）
- 本签是「工具」聚合页原生子签，命令面板没有对应的深入模式
