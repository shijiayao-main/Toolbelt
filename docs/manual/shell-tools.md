# Shell 工具

一句话：把常用的 adb / shell 命令做成一键按钮——选设备、点指令、看输出，不用自己敲命令行。

## 什么时候用

- 设备/手机连着电脑，想快速执行常用 adb 命令（截图、录屏、拉日志、看进程等）
- 每次都要百度/翻笔记才能想起命令怎么写，想固化成一键操作
- 需要对多台设备执行同一套命令
- **复现问题时想抓现场 logcat**——已收进「设备观测」页（Ctrl+6）的「logcat 实时抓取」，见 [logcat 实时抓取](logcat.md)

## 怎么用

### 第一次使用

1. 不用装 adb——应用自带。想确认是否可用，可去「设置」页（Ctrl+,）点「检测可用性」看版本号；Shell 类型按需选择
2. 回到「Shell 工具」页（dock 的「Shell 工具」图标，快捷键 Ctrl+3），点「刷新设备」——下拉框里出现你的设备即连接正常

### 执行一条指令

1. 顶部「选择设备」下拉框选中目标设备
2. 在指令卡片区找到想要的指令，点卡片上的执行按钮
3. 下方输出区实时显示命令输出；执行历史自动记录

### 自定义命令

- 点「新增自定义命令」，填命令名和命令内容，保存后和其他指令一样一键执行
- 支持从剪贴板批量导入自定义命令（「从剪贴板导入自定义命令」）
- 自定义命令按类型分组管理，可勾选多条「串行执行选中项」批量跑

### 实时抓取 logcat（已迁至「设备观测」页）

「logcat 实时抓取」面板已收进 dock 第六空间「设备观测」页（快捷键 Ctrl+6）——
抓取操作与产物衔接见 [logcat 实时抓取](logcat.md)。本页保留的是 adb / shell
快捷指令执行（含 `adb logcat` 这类长跑命令的常规执行入口）。

## 注意

- **多设备提示**：检测到多台设备时会出现选择提示「检测到多台设备，请选择命令执行的目标设备」——多设备不选直接执行可能失败
- 命令执行有超时上限，超时自动终止并提示「已达超时上限」
- 搜索框「搜索工具名或命令内容...」可以按名字或内容过滤指令卡片
## 常见问题

- **点执行没反应？** 先「刷新设备」确认设备在线；仍无设备多半是手机端未开 USB 调试或驱动/权限问题（设备状态栏会给出原因）
- **历史在哪看？** 执行历史在页面下方，点历史条目可查看当时输出、可回放重跑
