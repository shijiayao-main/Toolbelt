# 日志工作台

一句话：把日志拖进来、用一句话描述症状，自动跑「解密 → 时间过滤 → Tag 过滤」确定性管线，配好 AI 后再给出根因研判报告——全程证据可回看，报告可追问、可导出分享。

## 什么时候用

- 拿到一份设备日志，只知道「大概几点出了什么问题」，想先切出问题前后几分钟的日志再定位
- 几万行不想肉眼滚，想让 AI 顺着证据链帮你研判根因
- 复现问题后要给同事或工单一份能自圆其说的分析报告

## 怎么用

### 1. 进入工作台

点 dock 第 1 个空间图标「工作台」（快捷键 Ctrl+1），或按 Ctrl+K 搜「工作台」直达。这是启动后的家页。

### 2. 发起一次分析（左栏「分析输入」）

1. 在「拖入日志文件」区拖入或点选文件（.alog / .xlog / .txt，可多选）
2. 「问题时间点」填问题发生的时间——支持空格或 T 分隔、可省略毫秒，自动归一；旁边的「现在」按钮一键取当前时间。不填则不过滤时间、全量分析（较慢）
3. 「时间范围（±分钟）」填时间点前后各取多少分钟（有效范围 1–1440 分钟）
4. 「症状描述（必填）」一句话说清现象，例：设置页面黑屏无响应
5. 「Tag 正则（可选）」填了就按你的正则过滤；留空则 AI 结合知识库自己定
6. 点「开始分析」

- 还没配模型服务时用「只跑确定性管线」：只跑解密/时间过滤/Tag 过滤，不给根因结论；多文件时只分析第 1 个，界面会明确提示。要根因研判，先到 dock 系统区「AI 设置」配好模型
- 文件或症状没填齐，「开始分析」按钮上会直接写着缺什么

### 3. 看证据流与研判（中栏）

运行时中栏「证据流」实时滚动：

- 琥珀色块 = 管线各阶段产物（解密 → 时间过滤 → Tag 过滤），块头标着阶段与产物文件名，并有迷你时间直方图；「设为当前」把该产物切为主视图
- 紫色块 = AI 研判时间线
- 顶部可「在当前产物中搜索」；点日志行尾的 Tag 芯片，会同时把该 Tag 填进左栏正则（下次分析生效）、并在当前证据流就地过滤（即时可见）
- 点击带时间戳的日志行可展开上下文（展开中显示「（上下文回读中…）」）；行首 E/W 是错误/警告级别徽标
- 出现「已截断」提示说明产物太大只显示了一部分，点「查看完整产物」在应用内查看器里打开完整文件（行号跳转/搜索不出应用）
- 运行中随时可点「中止」

### 4. 路径授权确认卡（右下角）

研判中 AI 要读你没拖进来的文件时，右下角浮出「路径授权」确认卡：「允许」（或按 Enter）后本会话内该路径免确认；「拒绝」（或按 Esc）则跳过这次访问继续分析。

### 5. 看报告与追问（右栏「分析报告」）

- 报告按「结论 / 问题根因 / 完整时间线 / 关键依据 / 元数据」呈现，配「已确认 / 怀疑 / 已排除」计数徽章
- 「关键依据」里的时间点可点击，直接跳到证据流对应日志行；时间戳超出预览范围（产物太大被截断显示）时，会改为在应用内查看器打开完整文件并直接定位到该时间戳所在的那一行
- **证据 chip 直达查看器**：AI 给结论附了行号引用（证据块末尾的 `[证据 文件名:L起-止]` 标记，行号要求取自工具实际输出的 1 基行号）时，应用会**回读该行区间校验**——校验通过变成可点击芯片，点它在应用内查看器直接打开该文件并跳到起始行（结论可信度一键验货：引用行号点开即对原文）；校验不通过/旧格式引用降级为纯时间戳行，不出芯片；「导出 Markdown」会保留这些行号引用，并在「证据行原文」每条标注来源文件与行区间
- 「报告全文」可「展开全文 / 收起全文」；「打开报告文件」用系统默认程序打开自动落盘的完整报告
- 「对报告追问（增量研判）」输入框继续问（例：XPU 回传频率正常吗？），点「追问」——新结论追加、不改写原结论；追问需已配置 AI

### 6. 导出报告

点「导出 Markdown」生成可分享文件：

- 落点固定在你的用户目录 `~/Documents/Toolbelt/reports/`，文件名 `report-<记录编号>.md`；导出后在按钮旁显示完整路径，可一键复制或「打开所在文件夹」
- 同一条分析记录重复导出会**原位覆盖**旧文件——导出的永远是最新报告，含追问增量
- 研判运行中按钮置灰（提示「研判运行中，结束后可导出」），结束后再导
- 点「送飞书」**不出应用直接把报告发进飞书**：发送前自动重新导出（恒为最新报告），以文件消息发到飞书桥接设置里「测试 Chat ID」的会话——前提是桥接已在运行且已填该 ID，否则按钮置灰并提示原因

### 7. 存入历史案例库（根因存案）

报告区动作行有「**存案**」按钮（研判运行中置灰，提示「研判运行中，结束后可存案」）：

1. 点「存案」——弹出「存入历史案例库」编辑框，**标题 / 症状 / 根因 / 修复要点 / 证据日志 / 相关 TAG 六字段已从报告预填**（证据日志原文回读、TAG 取证据高频词），逐项可改可补；标题与症状必填
2. 点「存案」落库——存案即确认本报告根因（**不自动存案**，防止误案入库；同名案例覆盖旧案并明示）
3. 案例入库后，**后续研判的 AI 会先查历史案例**（同类症状「上次就是这么修的」起步）——检索支持按 tags 召回、多关键词与相关度排序，不用你做任何事

### 8. 回看与历史（左栏「历史 Run」）

每次分析都是一条记录，行内显示状态点（运行中 / 已完成 / 已中止 / 失败）、相对时间与文件数：

- 点行回看当时的时间线与报告——切换会弹确认（「切换分析记录」），原记录保留可随时切回
- 悬停出「改名」「删」；「删」不可恢复，连带证据流与报告一起删
- 「全部报告」进入报告页集中浏览历史报告

另外：XLog 解析 / Tag 过滤 / 文件分割各页产物卡上的「深度分析」，会自动把产物带进工作台并预填，不用手动拖。

## 应用内日志查看器

多处「查看」入口（工作台产物、logcat 抓取产物、任务卡产物、证据 chip……）打开的是同一个应用内查看器——大文件不整读（窗口分页续读，GB 级照常翻）：

- **跳转**：行号框回车直达；时间戳跳转；「上一处/下一处错误」「上一处/下一处警告」级别导航
- **文本搜索**：搜索框回车触发，命中行整列收集；同关键词再回车跳下一处，「上一处」反向回退
- **书签**（导航原语，标记「当前行」= 窗口首行）：「标记首行 / 取消标记」翻转、**「上一签 / 下一签」**双向跳、**「两签时间差」**算最近两签的行首时间戳差值（负差值明示倒流；无时间戳行给人话拒绝）、「清空书签」；书签行行首带 ◆ 前缀
- **命中小地图**：行流右侧一整列刻度——搜索命中行红色、书签行主色（同行既命中又书签显书签色），**点哪里跳哪里**（按比例定位行号）；GB 级文件搜出几百处命中时「哪里密哪里稀」一眼可见
- **书签持久化（工作台产物专属）**：从工作台分析记录里打开产物时，书签随该记录落盘——下次启动回看同一条记录同文件，书签自动恢复；产物文件内容变了则按行文指纹拒绝恢复旧签（不复活错位标记）。其他入口打开的文件书签只在当次会话有效
- 底部动作区：「深度分析」直投工作台研判、「送往 Tag 过滤」「送时间截取」进管线衔接、打开失败且判定为加密件时「送 XLog 解密」一键衔接

## 注意

- 分析产物（解密/过滤结果）落在**源日志文件同目录**，注意磁盘占用
- 研判运行中不能回看/切换其他记录，会提示「研判运行中，请先中止当前分析」——先点「中止」
- 程序意外中断留下的「运行中」记录，下次启动自动归为「失败」，不会永远卡住

## 常见问题

- **「导出 Markdown」点不了？** 研判还在跑——结束（或中止）后再导出
- **只有管线产物、没有根因结论？** 没配置模型服务——到「AI 设置」配好后走「开始分析」
- **多份日志只分析了一份？** 「只跑确定性管线」模式只分析第 1 个文件；全部分析需配置 AI 走「开始分析」
- **命令面板「暂存文件到 Buffer」的文件没生效？** 在工作台证据流顶部的「暂存区」里，点文件条目才真正载入（「点击载入并移出暂存」），× 是移除
